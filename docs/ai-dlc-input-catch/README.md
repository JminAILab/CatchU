# ai-dlc-input-catch — Catch 개편·새 Catch intent 입력

12월 intent(`260925-intent-12`)와 따로 여는 Catch 관련 AI-DLC intent(Catch 개편, 새 Catch)에 넣는 입력 문서다. **현행 기준이 아니다.** 현행 기준은 `docs/README.md` 「AI-DLC 산출물과의 관계」의 10월·12월 승인 문서다.

- [`CatchU_Catch_개편_입력.md`](CatchU_Catch_개편_입력.md) — 재분석 때 같은 작업이 중복 Catch가 되지 않게 하는 소속 저장, 무엇을 했는지 읽히는 Catch 제목·작업 사실·설명 초안, AI 초안 재료 고르기의 팀장 결정(2026-11-01·11-02)과 근거 실측, intent 시작 전 결정(§8).
- [`CatchU_새_Catch_입력.md`](CatchU_새_Catch_입력.md) — Catch 개편 다음 intent. 지원자가 고른 Catch에 판단을 자기 말로 적고 면접관이 시험해 볼 코드 자리와 원본을 붙이는 새 Catch의 정의, 2026-11-07\~11-09 팀장 결정, 설계안과 1\~3단계, intent 시작 전 결정(§8).
- 진행 이슈는 Catch 개편이 [#445](https://github.com/JminAILab/CatchU/issues/445), 새 Catch가 [#491](https://github.com/JminAILab/CatchU/issues/491)다. 이 폴더는 입력 자료이며 진행 현황판이 아니다.
- Catch 개편 입력이 바꾸는 10월 결정 문서 「Catch 제목」과 12월 범위 보완 「3-3」에는 대체 안내 한 줄씩만 더했고, 본문은 그 intent가 승인되기 전까지 그대로 현행이다.
