# ai-dlc-input-preset — 발행 프리셋 intent 입력

발행 방식을 프리셋 등록으로 바꾸는 AI-DLC 작업(intent)에 넣는 입력 문서다. **현행 기준이 아니다.** 현행 기준은 `docs/README.md` 「AI-DLC 산출물과의 관계」의 승인 문서다.

- [`CatchU_발행_프리셋_입력.md`](CatchU_발행_프리셋_입력.md) — 지원자가 자료 묶음(프리셋)을 미리 만들어 발행할 때 여러 개 등록하고, 받은 사람 화면에서 프리셋이 탭으로 나뉘어 보이게 하는 2026-11-18 팀장 결정, 지금 코드에서 바뀌는 자리, 범위와 담당, 바뀌는 기준, 정하지 않은 것과 기본값, 채택하지 않은 안.
- 진행 이슈는 [#597](https://github.com/JminAILab/CatchU/issues/597)이다. 이 폴더는 입력 자료이며 진행 현황판이 아니다.
