# AI-DLC 2.10.0 적용·검증 기록

## 목적과 적용 판본

12월 승인 요구사항·사용자 스토리 공유와 함께 프로젝트의 Codex용 AI-DLC를 2.8.1에서 2.10.0으로 갱신한다. 사용자 요청으로 [PR #179](https://github.com/JminAILab/CatchU/pull/179)과 [작업 #178](https://github.com/JminAILab/CatchU/issues/178)에 포함했으며 우선순위 P2를 유지한다.

- 적용 전 dev: `a7dcc8763158afe765468e39641d3bf3dbc12ace`.
- 승인 문서 공유 커밋: `f552efabba3080f7d5d997f00ddb2b51f3055f03`.
- 갱신 출처: 기존 `chore/aidlc-2.10.0`의 `83617f8c732e3e36d63e2eb243eb8cfb3ea8589f`.
- 출처 커밋의 `.codex/`, `.agents/`, `AGENTS.md` 관리 블록과 `.gitignore` 변경 161개 파일을 그대로 적용했다. 출처의 공용 진단 감사 기록은 승인 문서 공유 시 이미 가져왔으므로 기존 전체 이력을 유지했다.
- 도메인 설계 재개, 제품 구현, 승인 원본 변경은 수행하지 않았다.

## 검증 결과

검증일은 2026-09-29이며 위 문서 공유 커밋에 2.10.0 변경을 적용한 상태에서 검사했다.

| 검사 | 결과 |
|---|---|
| 기계 런타임·프로젝트 스탬프 | 모두 2.10.0, Codex CLI 0.157.1 |
| `aidlc doctor --verbose` | 오류 0건·경고 2건, 진단 감사 기록은 별도 파일로 보존 |
| 공식 구조 검사 | 33/33 단계 스키마, 12개 scope 유효, 그래프 순환 0개, intent 목록과 디렉터리 일치 |
| 적용 파일 비교 | 갱신 파일 161개가 출처 커밋과 바이트 단위로 일치 |
| 기존 자료 보존 | 기존 `aidlc/`, 입력 문서, `web/`, `api/`, `worker/`의 추적 파일 370개 해시 불변 |
| 팀 지침·사용자 scope | AGENTS 팀 관리 영역, `catchu-definition` 원문과 8 EXECUTE/25 SKIP 구성 보존 |
| 형식 | Codex TOML·도구 데이터 JSON 파싱, 갱신분 `git diff --cached --check` 통과 |
| 12월 상태 | 사용자 스토리 승인·도메인 설계 직전 park 유지 |

경고 2건은 이 컴퓨터의 오래된 임시 프로젝트 등록과 업데이트 조회 캐시에 관한 것이다. 프로젝트 오류가 아니므로 이 PR에서 다른 작업 경로나 기계 설정을 정리하지 않았다. scope 권고 47건과 기존 팀 규칙 중복 안내는 공식 진단의 오류로 판정되지 않았으며, 이번 갱신으로 기존 규칙을 수정하지 않았다.

## 팀 적용과 검증 한계

PR 병합 뒤 변경을 받은 팀원은 실제 작업 폴더에서 설치 런타임과 프로젝트 버전이 2.10.0인지 확인하고 `aidlc doctor`를 실행한다. 실행 중인 세션은 변경된 도구 설정을 모두 다시 읽었다고 가정하지 말고 새 세션에서 확인한다. 문서 열람만으로 정지한 12월 작업을 재개할 필요는 없다.

이번 검증은 이 macOS 환경의 Codex 설정·공식 구조 진단이다. 다른 팀원의 컴퓨터·다른 하네스와 전체 워크플로우의 실제 단계 진행은 검증하지 않았다. 제품 테스트와 NCP 배포는 이번 도구·문서 변경에 해당하지 않는다.

## 다음 refresh 시 보존할 것

기존 갱신 커밋의 방침을 유지한다. `catchu-definition` scope 파일과 scope-grid 항목을 함께 보존하고, 필요하면 공식 `aidlc engine gen scope-table` 결과로 범위 표를 갱신한다. 공급자·모델은 사용자 설정을 상속하며 프로젝트에서 고정하지 않는다. 과거 reviewer 모델 주석과 bare bun 대체 패치는 공식 배포본에 해결됐으므로 다시 적용하지 않는다. 기존 승인·감사·입력 원본과 AGENTS 팀 관리 영역은 갱신 대상으로 삼지 않는다.
