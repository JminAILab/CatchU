# 팀 그라운드 룰 (2026-08-04 확정)

> 프로젝트 지식용. 팀이 합의한 운영 규칙의 정본. 변경 시 이 파일을 갱신하고 날짜를 남긴다.

## 회의 운영

- 데일리 스크럼: 오전 9시 30분 시작, 20분 이내로 진행한다.
- 주간 회의: 월요일에 진행한다.
- 주간 회고: 금요일에 진행한다.
- 정기 회의는 월·금 오전. 일정 변경 시 팀원에게 사전 공유한다.

## 문제 해결과 기록

- 버그를 30분 이상 해결하지 못하면 GitHub Issue를 작성한 후 Slack으로 도움을 요청한다.
- 도움을 준 사람도 해결 과정과 결과를 기록한다.
- 모든 팀원은 주 1회 작업일지를 작성한다.

## 근무와 연락

- 야근은 일정상 필수 기능 완료가 어려울 때만 진행한다.
- 주말 작업도 야근과 동일한 기준을 적용한다.
- 긴급하지 않은 업무 연락은 퇴근 후 및 공휴일에 하지 않는다.

## 일정 공유

- 시험·면접 일정이 생기면 팀원에게 즉시 공유한다.

## 아이디어와 의사결정

- 새로운 아이디어는 바로 개발하지 않고 팀원과 일정 영향을 확인한 후 진행한다.
- 의견이 2:2로 갈리면 강사님 및 보조강사님의 의견을 듣고 재논의한다.
