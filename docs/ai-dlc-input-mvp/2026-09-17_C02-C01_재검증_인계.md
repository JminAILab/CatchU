4. Git을 읽을 때 외부 diff/textconv를 막는 명시 옵션을 사용하고 실제 명령을 기록한다. checkout/pull/fetch/clone/submodule/LFS·설치/빌드·저장소 코드 실행은 이번 기본 경로에 넣지 않는다. PoC의 import 시 실행되는 스크립트를 바로 호출하지 않는다. 필요한 자료가 없으면 부족 조건만 보고하며 새 수집이나 실행 범위를 자동 확장하지 않는다.
5. 발췌 위치/줄 범위, 부모→변경 SHA, 파일의 추가/기존 여부, 관측한 코드/주석 구분, 생략·누락/잘림 기준과 추출 시각(KST/UTC)을 고정한다. API 저장자료에 patch가 없는 것과 자체 발췌로 자른 것을 구분한다.
6. 이름·계정·이메일·원격 URL·개인 경로·실제 비밀값을 사전에 탐지·제거/가명화한다. 의미 있는 코드명은 필요한 최소만 남기되 개인 식별정보와 구분한다. 가명↔실명 대응표도 원문 사본과 같은 삭제 대상으로 로컬에만 둔다. **실제 비밀값은 누출 시험에도 넣지 않는다.**

별도 확인 사항: 해당 세션의 원본 접근·해시 차이, 필요한 커밋 객체/근거 존재, 새 발췌의 동의 범위, Claude 세션으로 전달되는 최소 자료의 범위 및 그 세션의 보관 설정. 기존 동의는 **OpenAI API 최소 발췌 전송**이며 다른 제공자에 원문을 통째로 전송하는 허용이 아니다. 실행 지원에 불필요한 원문은 Claude 도구 출력/대화/로그에 남기지 않는다. 그 환경의 추가 외부 전송이 필요하면 먼저 범위와 조건을 사용자에게 확인한다.

### 비용 근거·차단

2026-09-17 공개 문서 확인: Luna 입력 $0.20/백만, 캐시 입력 $0.02/백만, 출력 $1.20/백만, 캐시 쓰기 일반 입력의 1.25배. `medium` 지원. 실제 계정 접근은 이번 인계 준비에서 검사하지 않았다. [모델/가격 공식 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna).

캐시 할인을 기대하지 않고 모든 입력을 쓰기 단가 $0.25/백만으로 잡으면:

```text
호출당 최대 = (20,000 × 0.25 + 8,000 × 1.20) / 1,000,000 = $0.0146
새 3호출 최대 = $0.0438
```

출력 제한에는 추론 토큰이 포함된다. 길이 제한으로 `incomplete`가 되거나 가시 응답이 없더라도 비용이 발생할 수 있으며 자동으로 상한을 높이지 않는다. [추론·출력 상한 공식 문서](https://developers.openai.com/api/docs/guides/reasoning).

- **$3 이내 기존 예산 조건 유지**, 자동으로 새 $3 예산을 열지 않는다. 과거 6회 usage 기반 추정 $0.00521185는 청구 확정액이 아니다. 계산상 잔여는 $2.99478815지만 실제 잔액으로 보고하지 않는다.
- 청구가 확인되지 않으면 보수적으로 이전 최대 예약 $0.0876을 차감한 **$2.9124 이내**를 이번 계획 비교에 쓸 수 있다. 다른 사용/미확정 비용도 반영하고 실제 가용 예산은 호출 전 사용자와 확인한다. 과거 6회 한도가 재개되는 것은 아니며 **새 최대 3회에 대한 별도 호출 허용**이 필요하다.
- 매 호출 직전 `기존 사용/미확정 예약 + 이번 누적 사용/예약 + 다음 호출 최대비용 ≤ $3` 및 실제 가용 잔액 조건을 검사한다. 못 확인하면 중단. 타임아웃/응답 유실도 시도 1회로 세고 최대비용을 예약하여 재호출로 회수하지 않는다. SDK/HTTP 자동 재시도도 0.
