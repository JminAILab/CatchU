# 10월 MVP 시작 요청 — 회의 후속 입력

기록일: 2026-09-14
출처: 팀원 1인 사용자의 두 번째 AI-DLC intent 시작 요청과 회의 결과 전달.
기준: 저장소 커밋 `622416602cedbaaefec8a3becd19c7adefd0517a`의 [MVP 입력](CatchU_mvp_input.md) §2.4·§2.5·§7.1. 해당 입력 파일의 마지막 변경 커밋은 `757eef3e2a49dd500e3cf33d703534c0ac2b5b59`다.
지위: **후속 입력**. 담당 작업에 대한 회의 결과를 기록하며 AI-DLC 공식 계획·설계·단계 승인이나 구현 완료를 뜻하지 않는다.

## 회의에서 확인한 내용

사용자가 전달한 회의 결과: “§2.5 중 팀원 2·3·4의 담당 작업은 회의에서 변경 없이 진행하기로 했다.”

| 담당 | 회의에서 진행하기로 한 작업 | 첫 결과물 기준 |
|---|---|---|
| 팀원 2 | 회원·기본 프로필, 내 자산·대표 프리셋 | 로그인·프로필, Catch 확인·공개·숨김·불일치 표시, 대표 주장·Catch 선택 흐름과 와이어프레임 |
| 팀원 3 | 공유 링크 발급·관리, 수신자 열람 | 발급자·수신자 흐름, 비밀번호·중단·만료·자료 열람 와이어프레임 |
| 팀원 4 | 서비스 홈, 저장소 선택·분석 진행·실패·재시도 화면 프론트엔드 | 먼저 홈 와이어프레임, 이후 분석 화면으로 확장 |

팀원 1은 공통 조율, PoC 분석, GitHub 분석 서버 처리를 맡으려는 의사를 밝혔다. 첫 결과물은 PoC 분석 요약, 분석 입력·상태·결과 데이터 초안, 전체 기능 담당표다. 실제 GitHub 계정과 팀원 번호의 대응, 작업량·날짜는 이 입력으로 확정하지 않는다.

첫 화면 결과물은 MVP 입력 §2.5에 따라 목적·진입·정보·버튼·이동과 관련 빈 상태·로딩·실패·미정 질문을 설명한다. 완성 디자인이나 실제 API 연결은 첫 제출의 필수 조건이 아니다. 담당자는 자신의 영역을 설계·코딩·테스트하며, 사람의 책임 배분과 AI 에이전트 역할은 별도로 기록한다.

## 여전히 검토·결정할 내용

- 화면 연결 지점·API 계약·공통 및 미배정 작업은 이번 회의에서 논의하지 않았다. §2.5의 담당 경계 설명은 관련 작업의 설계 시점에 확인할 제안으로 유지한다.
- 내부 선택 공유·품질 신호·검토 권한, 운영 기록·신규 처리 중단·재개, 환경 준비·수동 배포·복구, 통합 검증의 구현·검토·운영 책임을 팀에서 배분한다. 선택 공유 내용의 검토자가 팀원 1이라는 사실로 구현·운영까지 배정하지 않는다.
- 독립 화면 초안은 병행할 수 있다. 실제 API·저장·권한 연결 전에는 해당 공통 설계와 계약을 확인한다. 초안이 제출되지 않았다면 존재한다고 가정하지 않는다.
- 각 화면 초안의 작성 주체·정본·리비전을 확인하고 관련 AI-DLC 단계에서 검토·보완해 재사용한다. 팀장 세션에서 같은 결과물을 중복 작성하지 않는다.

## 공식 계획 제안에 반영할 요청

- 첫 intent의 승인된 제품 행동·FR/NFR ID를 재사용하고, 10월 적용과 후속 결정만 구체화한다. 첫 intent를 다시 열거나 승인 이력을 소급 수정하지 않는다. 재사용은 새 단계 완료나 승인과 다르다.
- PoC 분석은 코드·의존성·입출력·흐름, 확인 가능한 실행 결과·한계, 유지·수정·제외 근거, 서비스 요구사항과의 차이, 재사용·재설계·추가 검증을 다룬다. 분석 전 코드 복사나 재사용을 근거로 한 일정 단축 확약은 하지 않는다. 규칙 기반 결과는 LLM 초안 생성 검증과 구분한다.
- 공통 데이터·권한·상태 모델을 확인하고 구현·검토 가능한 유닛으로 분할한 뒤 API 계약과 의존성을 정한다. 사람별 큰 담당 영역을 유닛 하나로 고정하지 않는다.
- 각 담당자가 연결 구현을 시작할 때 필요한 설계·계약·검증 기준, 첫 통합 흐름과 전체 기능 검증, NCP 수동 배포·외부 URL·자료 유지·복구 확인의 검토 지점을 제안한다. 자동 배포 파이프라인은 제외한다.
- 10월 필수 범위는 MVP 입력 §1·§3을 유지한다. 대표 구성은 링크 발급 필수 조건이 아니다. 미완료 기능을 임의 제외하거나 12월로 넘기지 않는다.
- NCP 계정 수령·권한, 서비스 LLM API 제공자·모델·등급, GitHub OAuth 준비는 실제 확인한다. 예정일이 지났다는 사실은 준비 완료가 아니다. 팀원 1의 조율·자문과 팀원 4의 학습 부담을 가용량에 반영한다.

## 입력의 효력과 실행 기록

원래 §2.5 전체가 제안이라고 적힌 부분 중 **팀원 2·3·4의 담당 작업 진행 여부**에만 이번 회의 결과를 후속 입력으로 적용한다. 연결 계약과 공식 단계 승인은 그대로 미결이다. 기존 입력·승인본을 소급 변경하지 않고 새 intent가 이 후속 입력을 함께 참조하도록 한다.
