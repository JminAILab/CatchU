# 9/16 회의 결정 — 공통 화면과 공유 자료

지위: 9/15 오후·9/16 오전 회의에서 전달된 결정을 정리한 후속 입력. 승인된 요구사항의 과거 기록은 유지한다. 알림·DM·피드는 12월 범위이며, 10월 표시 방식과 이력서 적용 시점은 별도로 정한다.

## 1. 내비게이션·알림·DM

| 항목 | 반영 기준 |
|---|---|
| 상단 구성 | 로고·내 자산·채용공고·공유 링크·알림·프로필. 순서는 미정 |
| 홈·대표 구성 | 별도 홈 메뉴 없이 로고로 홈 이동. 대표 구성은 내 자산 안에 배치 |
| 프로필 | 클릭하면 모달을 열고, ‘프로필 보기’로 상세 프로필 이동 |
| 알림 목록 | 상단 종 아이콘으로 진입 |
| 새 알림 | 숫자로 표시. 꺼 둔 알림은 집계에서 제외. 색 변경·움직이는 효과는 사용하지 않음 |
| 읽음 표시 | 안 읽음 검정, 읽음 회색. 빨강은 전체 시스템 공지에만 사용 |
| 알림 설정 | 프로필 모달과 알림 목록 톱니바퀴에서 같은 설정 화면으로 이동 |
| 알림 필터 | 개발 후순위 |
| DM | 상단 메뉴·알림과 분리해 우측 하단에 배치 |

9/15의 DM 좌측 하단·새 알림 색 변경 결정을 각각 **우측 하단·숫자 표시**로 대체한다. DM 아이콘(말풍선/새), 숫자 형식(99+ 등), 전체 색상 체계는 미정이다.

## 2. 홈

GitHub 계정 연결과 분석할 저장소 연결을 서로 다른 단계로 보여 준다.

| 상태 | 안내와 이동 |
|---|---|
| GitHub 미연결 | GitHub 연결 안내 → 프로필 연결 화면 |
| GitHub 연결·레포 미연결 | 레포 연결 안내 → 내 자산 GitHub 탭 |
| 둘 다 연결 | 시작 안내를 반복하지 않고 피드 중심 홈 표시 |

미연결 두 화면은 상단에 **‘GitHub 연결 — 레포 연결’**을 함께 표시하고 현재 단계만 진하게 보여 준다. 설명과 ‘연결하러 가기’ 버튼을 두며, 안내 아래에는 동일하게 피드를 표시한다. 설명 문구의 최종 카피는 별도로 다듬는다.

‘연결된 레포’는 기존 기준대로 분석 요청이 접수된 저장소가 1개 이상인 상태다. 조회 중·실패를 미연결로 단정하지 않는다. 비로그인 홈의 서비스 소개·가상 Catch·‘Google로 시작하기’는 유지한다.

피드는 **12월 기준**이다. 무한 스크롤을 사용하고 별도 최상단 이동 버튼은 두지 않으며, 홈 이동은 로고로 연결한다. 상단 필터를 도입하면 최상단 이동 버튼을 재검토한다. 10월의 피드 대체 구성은 미정이다.

## 3. 공유 링크 방문자 헤더

공유 링크 방문자는 **로그인 여부와 관계없이 일반 서비스와 다른 헤더**를 사용한다. 발행자용 ‘내 자산’ 등 관리 메뉴를 그대로 노출하지 않는다.

**‘아이콘 하나 + 우측 로그인 버튼’은 검토안**이다. 로그인한 방문자의 표시, 구체 메뉴와 로고 이동 대상은 아직 정하지 않았다.

## 4. 이력서

수신자가 필요한 자료를 한 화면에서 확인하도록 이력서를 공유 자료에 다시 포함한다. 9/16 오전 추가 논의에서는 **서비스가 이력서 틀을 제공하기보다, 지원 회사 양식으로 작성한 이력서 파일을 업로드해 링크에 포함하는 방향**을 선호했다([논의 기록](https://github.com/JminAILab/CatchU/issues/56#issuecomment-5691926544)). 적용 시점(10월/12월), 파일 형식·용량, 업로드 위치와 열람 방식은 #56에서 구체화한다.

팀장 댓글에 따라 기존 FR5.2–FR5.4의 서류 처리 원칙을 이력서에도 적용하는 방향으로 정리한다.

- 링크별로 포함할 서류를 선택한다. 서류 없이도 발행할 수 있고 선택한 서류만 열람한다.
- 업로드 방식은 발행 당시 내용을 보존한다. 원본 수정·삭제가 기존 발행본을 자동 변경·삭제하지 않으며 관련 링크와 중단 방법을 안내한다.
- 파일과 외부 URL의 차이는 설계·연결 계약에서 구분한다. 외부 URL의 일반적인 특성 안내는 필수로 두지 않는다.

다운로드는 허용 선호 의견이며 최종 결정은 아니다. 관련 의무·동의·안내·보관 기준과 기존 다운로드 옵션 제외 결정의 관계를 확인한 뒤 정한다. 담당·일정과 최종 확인 주체·근거도 #56에 남긴다.
