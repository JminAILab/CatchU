## 2. 홈

홈의 CTA 분기와 ‘연결된 repo’ 기준은 [후속 입력](2026-09-14_followup.md)의 「팀장 확인 (2026-09-15): GitHub 연동·자산 탭 분석 경로」를 따른다. 이 절에는 9/16에 새로 정한 표시 방식만 적는다.

- **단계 표시:** 미연결 안내 화면 상단에 ‘GitHub 연결 — 레포 연결’을 함께 표시하고, 현재 단계만 진하게 보여 준다.
- **설명과 버튼:** 현재 단계의 설명과 ‘연결하러 가기’ 버튼을 둔다.
- **안내 아래 피드:** 두 안내 화면 모두 안내 아래에 피드를 표시한다. 피드는 12월 범위이며, 10월의 대체 구성은 미정이다.
- **카피:** 설명 문구의 최종 카피는 별도로 다듬는다.
- **조회 상태:** 연결 여부를 조회 중이거나 조회에 실패한 상태를 미연결로 단정하지 않는다.

## 3. 공유 링크 방문자 헤더

공유 링크 방문자는 **로그인 여부와 관계없이 일반 서비스와 다른 헤더**를 사용한다. 발행자용 ‘내 자산’ 등 관리 메뉴를 그대로 노출하지 않는다.

**‘아이콘 하나 + 우측 로그인 버튼’은 검토안**이다. 로그인한 방문자의 표시, 구체 메뉴와 로고 이동 대상은 아직 정하지 않았다.

## 4. 이력서

### 결정: 12월에 포함

**2026-09-16, 팀장은 이력서를 자기소개서·포트폴리오와 같은 12월 범위에 포함하기로 결정했다**([결정 댓글](https://github.com/JminAILab/CatchU/issues/56#issuecomment-5692700641)). 10월 MVP 화면에는 서류 흐름을 넣지 않는다.

기존에는 기업이 이미 이력서를 보유하고 있고 기술 면접관의 주요 관심 자료가 아니라는 이유로 제외했다. 9/15 회의에서 수신자가 필요한 자료를 한 화면에서 함께 확인할 수 있도록 재포함하기로 했고, 9/16 팀장 댓글에서 적용 시점을 12월로 정했다.

**FR5.2~FR5.4는 서류 종류와 무관하게 같게 적용한다.**

- **링크별 선택(FR5.2):** 링크에 포함할 서류를 선택한다. 서류 없이도 발행할 수 있으며, 선택한 서류만 해당 링크에서 열람한다.
- **발행본 보존(FR5.3):** 업로드 파일은 발행 당시 내용을 보존한다. 외부 URL은 주소만 보존하며, 외부 서비스의 내용·권한까지 고정됐다고 표시하지 않는다.
- **원본 변경 안내(FR5.4):** 원본 수정·삭제 전에 관련 링크 목록, 발행 당시 내용이 유지된다는 점, 링크 중단 방법을 안내한다. 원본 수정·삭제로 기존 발행본이 자동 변경·삭제되지는 않는다.

### 제공 방식: PDF 파일 업로드 확정

9/16 오전에는 서비스가 이력서 틀을 제공하기보다 **지원자가 지원 회사 양식으로 작성한 파일을 업로드하는 방향**을 선호했다([논의 기록](https://github.com/JminAILab/CatchU/issues/56#issuecomment-5691680339)). 이후 9/16 팀장 답변에서 **PDF 파일 업로드로 확정**했고, 9/17 [결정 댓글](https://github.com/JminAILab/CatchU/issues/56#issuecomment-5715760038)로 기록했다. 외부 링크는 이력서 제공 방식에 포함하지 않는다.

### 남은 결정의 처리 (2026-09-30 갱신)

9/16에 #56으로 넘긴 네 항목은 아래처럼 정해졌거나 12월 요구사항으로 옮겨졌다. #56은 2026-09-29 [팀장 결정](https://github.com/JminAILab/CatchU/issues/56#issuecomment-5885936603)으로 닫았다.

| 항목 | 현재 상태 |
|---|---|
| 업로드 위치 | 내 자산의 이력서 탭에 여러 벌 등록하고, 링크를 발행할 때 고른다(2026-09-24 팀장 결정, [12월 범위 문서](../ai-dlc-input-december/CatchU_12월_범위_보완.md) §2) |
| 열람·다운로드 | 서비스 안에서 열람한다. 12월에는 다운로드와 링크별 다운로드 허용 설정을 제공하지 않는다. 영구 제외는 아니다(2026-09-26 팀장 결정) |
| 파일 용량 | 서류 설계와 개발 착수 전에 정한다. 12월 요구사항의 후속 미결에서 추적한다 |
| 보관 기준 | 만료·중단 뒤 정한 기간 보관하고 자동 파기한다. 기간과 자료별 근거는 12월 요구사항의 후속 미결에서 추적한다 |

주민등록번호가 들어간 이력서 파일은 받지 않는 방향이다(2026-09-29 팀장 결정). 확인·발견 시 처리 방법은 12월 설계에서 정한다. 기준 문서는 [12월 요구사항](../../aidlc/spaces/default/intents/260925-intent-12/inception/requirements-analysis/requirements.md)의 「작성자가 서류를 등록하고 공유본별로 선택한다」와 「후속 미결」이다.

**서류 공통 원칙:** 파일과 외부 URL의 차이는 설계·연결 계약에서 구분하되, 외부 URL의 일반적인 특성 안내는 필수로 두지 않는다.
