# 개발 마일스톤 해석 — 새 세션 검증 기록

> 지위: 공통 지침 수정 후 두 CLI에서 각 1회 수행한 읽기 전용 확인 기록. [#325](https://github.com/JminAILab/CatchU/issues/325)의 검증 증거이며 제품 구현·실제 분석·사람의 PR 승인을 뜻하지 않는다.

Codex·Claude의 새 세션 모두 #322·#323이 필요하고 현재 분리가 적절하며, 확정된 12월 문구를 지금 반영하기 위해 별도 10월판을 만들 필요가 없다고 판단했다. 두 실행에서 공통 문서의 실제 읽기를 확인했고 사본 변경은 0개였다. 부수 제안의 내용까지 같다는 뜻은 아니다.

## 변경한 기준과 진입 경로

- [문서 안내 「개발 목표와 마일스톤」](../README.md#개발-목표와-마일스톤)에 10월 내부 중간 마일스톤과 12월 공개 목표의 관계, 확정 산출물의 선반영, 현재 실행 계약의 경계를 둔다.
- [AGENTS.md](../../AGENTS.md)는 이슈 필요성·범위·완료 기준 검토 전에 그 절과 해당 이슈의 후속 결정을 읽게 한다. [CLAUDE.md](../../CLAUDE.md)는 기존 `@AGENTS.md` 참조를 유지하며 같은 경로를 따른다.
- [작업관리](../CatchU_작업관리.md)와 [12월 안내](../CatchU_12월_승인문서_안내.md)는 같은 정본으로 연결한다. AI-DLC 관리 블록·하네스·승인 원본과 제품 코드는 변경하지 않는다.

## 입력과 실행 조건

- 시험 판본: `e48ab0464be43996748e4d5fb886d6c698d87ed7`(기준 dev `5b638e28350b307ef32b68532efdf865fb05fae5` 위의 지침 변경). 최종 PR의 검증 기록·색인 추가는 시험 이후다.
- 추적된 관련 문서·요구사항·계약·API 소스와 #322·#323·#252·#138 본문·댓글 snapshot을 별도 사본에 고정했다. 총 227개 파일의 실행 전 SHA와 프롬프트가 두 실행에서 완전히 같다.
- 원래 질문과 자료 위치·읽기 전용 제약만 전달했다. 이전 대화, 사용자의 정정 설명, 기대 답변이나 이 검증 기록을 프롬프트에 넣지 않았다. 새 공통 기준은 저장소 문서를 통해 읽게 했다.
- resume·continue·fork를 쓰지 않고 매번 새 세션을 실행했다. `--model`·effort 인자는 지정하지 않았다. 개인 설정을 제외했으므로 사용자의 평소 모델·effort를 그대로 재현한 시험은 아니다.
- 원본 저장소의 `.git`, 비밀값, 개인 설정, 기존 대화·AI-DLC 감사 기록, 과거 실험 원문·검증 결과는 사본에 복사하지 않았다. CLI 인증에는 기존 로그인을 사용했다.
- Codex는 `exec --ephemeral --sandbox read-only --ignore-user-config --ignore-rules --skip-git-repo-check --json`을 사용했다. Claude는 `-p --no-session-persistence --restricted`와 `Read,Glob,Grep`만 제공하고 MCP·훅·자동 메모리를 제외했다. 실제 인자·프롬프트·입력 SHA·완료된 도구 동작·최종 응답은 [구조화 증거](2026-10-17-milestone-evidence.json)에 있다.

Codex의 완료된 명령 11개는 파일 목록·검색·읽기와 snapshot JSON 출력이었다. Claude의 도구 호출 24개는 `Read`·`Glob`·`Grep`뿐이었다. 명시적 도구 동작에서 외부 원격 접근·개인 파일 열람·쓰기 명령은 관찰되지 않았다. 모델 서비스 통신과 CLI의 정상 인증·초기화는 별개다.

처음 제한된 실행 환경에서 Codex는 모델 호출 전 app-server 초기화 권한 오류, Claude는 인증 401로 종료했다. 이 두 실패는 행동 판정에서 제외하고 보존했다. 같은 읽기 전용 설정을 정상 CLI 실행 권한으로 재시도한 위 두 실행은 정상 종료했다. 권한·인증의 초기 실패를 지침 준수나 내용 판단의 실패로 세지 않는다.

## 확인 범위와 한계

- 두 도구에서 각각 한 번의 관찰이다. 수정 전과의 비교 시험이나 통계적 재현성·품질 향상·팀 전체 환경의 동일 행동을 입증하지 않는다.
- 네이티브 진입 지침 주입 전문의 별도 적재 이벤트는 CLI JSON에 없어 직접 입증하지 못했다. 프롬프트에서 진입 파일명을 지시하지 않은 새 세션에서 자동 발견을 허용했고, 두 모델의 공통 문서 도달과 최종 판단을 확인한 범위다.
- 이번 시험의 모델·effort는 통제하지 않았다. Claude 모델은 init 기록에서 확인했고 Codex 모델·두 effort 수준은 미확인으로 남긴다.
- 이슈 snapshot과 포함된 소스만 검토했다. 실제 최신 원격 상태·Project 설정·제품 실행·GitHub/LLM 분석·배포를 시험한 결과가 아니다. 원문 이벤트 로그 전체와 도구 응답 본문은 저장소에 싣지 않고, 증거 JSON에는 완료 동작·입력 해시·최종 응답을 둔다.
