# ai-dlc-input-reorg — 문서 개편 intent 입력

11월 개발(12월 intent `260925-intent-12`)이 끝난 뒤 여는 문서 개편 AI-DLC 작업(intent)에 넣는 입력 문서다. **현행 기준이 아니다.** 현행 기준은 `docs/README.md`의 문서 목록과 「AI-DLC 산출물과의 관계」다.

- [`CatchU_문서개편_입력.md`](CatchU_문서개편_입력.md) — 바깥 사람이 읽는 첫 화면과 팀원·AI가 읽는 지침을 지금 기준으로 다시 묶는 이유, 2026-11-14 팀장 결정(11월 방식 끝내기, `team.md`와 `org.md`의 11월 문장 교체, 12월 intent 보관, 진행 순서), 첫 화면·AI 지침의 범위, intent 전에 할 일, 정하지 않는 것과 남는 위험.
- 진행 이슈는 [#553](https://github.com/JminAILab/CatchU/issues/553)이고, 하위 이슈는 [#549](https://github.com/JminAILab/CatchU/issues/549)(입력 문서)·[#550](https://github.com/JminAILab/CatchU/issues/550)(12월 intent 닫기)·[#551](https://github.com/JminAILab/CatchU/issues/551)(AI 지침)·[#552](https://github.com/JminAILab/CatchU/issues/552)(첫 화면)다. 이 폴더는 입력 자료이며 진행 현황판이 아니다.
