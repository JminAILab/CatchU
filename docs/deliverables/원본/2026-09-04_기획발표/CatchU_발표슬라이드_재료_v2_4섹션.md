## 9. 차별성 세 가지 〔창의성·차별성〕

**화면** — 3단.

**① 점수가 아니라 근거**
지원자를 채점하지 않는다. "무엇을 했나 × 어느 기록이 근거인가"를 카드로 만들고 판단은 읽는 사람이 한다. 근거 없는 문장은 카드가 되지 못한다.
판별 기준 — *"점수 모델이 이 문장을 쓸 수 있는가." 쓸 수 있으면 우리 것이 아니다.*

**② 결과물이 아니라 판단의 흔적**
카드의 단위는 기능이 아니라 사건. 가장 값진 필드는 **"시도했다가 버린 것"** — 완성 코드에는 없고 커밋 시계열에만 남는다. 코드가 AI로 생성되는 시대에도 사람에게 남는 층위.

**③ ATS를 대체하지 않고 옆에 선다**
구직자가 자산을 쌓는 곳, 기업은 열람하러 들어온다. 채용은 기업의 기존 ATS에서 돈다. 기존 절차를 거스르지 않는다.

하단 작게 — 설계 원칙: 점수·등급·적합도 % 없음 / AI 생성 판별 안 함(검증은 면접의 몫) / public 저장소 + 본인 동의만 / 공동 기여자 정보는 수집 시점에 제거

**멘트** — ②를 가장 길게. "완성된 코드를 보면 '낙관적 락을 썼다'까지만 보입니다. 커밋을 시간순으로 보면 '비관적 락을 먼저 시도했다가 바꿨다'가 보입니다. 저희가 꺼내는 건 이 두 번째입니다."

## 14. 무엇으로 성공을 재나 〔목표·성과지표〕

**화면**

|         | KPI                          | 묻는 것                                             | 어떻게 재나                                                  |
| ------- | ---------------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| ⭐ 1순위 | 카드가 **사실과 맞는가**     | AI가 쓴 카드를 믿을 수 있나                         | 카드를 만들기 **전에** 팀원 2명이 각자 GitHub 원본만 보고 "이 레포에서 이 사람이 한 일" 정답표를 쓴다 → 카드 한 장씩 정답표와 대조해 ○× |
| ⭐       | **이 사람이** 한 일이 맞는가 | 팀 프로젝트에서 남의 커밋을 내 것으로 붙이지 않았나 | 같은 정답표. 팀 프로젝트 레포만 대상                         |
| ⭐       | **잊었던 경험**을 찾아주는가 | 사용자가 이미 아는 것만 보여준 건 아닌가            | 수료생 5명: 먼저 CatchU 없이 30분간 자기 경험을 써본다 → 카드를 본다 → "맞다, 이것도 했었다"가 몇 건 나오는지 |
|         | 근거까지 **닿는가**          | 카드에서 원본 커밋까지 갈 수 있나                   | 위 5명에게 "이 카드의 원본을 찾아보세요" 과제                |

- **목표 숫자는 11월 초에 정한다.** 먼저 LLM 없이 규칙만으로(키워드+파일 확장자) 카드를 만들어 같은 정답표로 재고, 그것보다 얼마나 나은지로 목표를 잡는다. "왜 90%인가"에 "규칙만으로 하면 ○○%였기 때문"이라 답하기 위해서다.
- **비율이 아니라 0건이어야 하는 것**: 깨진 근거 링크 · 남의 기여를 내 것으로 표시한 카드
- **안 재는 것**: 취업 성공률(우리가 관여하는 구간이 아님) · 클릭·체류 시간(늘어도 좋은 건지 알 수 없음)

**멘트** — "저희 KPI는 전부 '정답표와 대조'입니다. 정답표는 카드를 보기 전에 사람이 씁니다. 카드를 먼저 보면 정답이 카드 쪽으로 끌려가기 때문입니다. 목표 숫자가 비어 있는 건, 규칙만으로 먼저 재보고 그보다 얼마나 나은지로 정하기 위해서이고 그 시점이 11월 초입니다."

**디자인 메모** — 1순위 행 강조. "어떻게 재나" 열이 가장 넓어야 한다. 목표값 줄은 빈칸이 아니라 "11월 초 확정"으로 보이게. GT·baseline·귀속 같은 단어는 화면에 쓰지 않는다.
