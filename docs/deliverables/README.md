# 중간 평가 제출 산출물

2026년 10월 1~2일 중간 발표에 맞춰 제출하는 CatchU 산출물이다. 팀 Jaemin_AI, 과제명 "이력서-채용공고 텍스트 매칭 시스템". 작업 이슈는 [#125](https://github.com/JminAILab/CatchU/issues/125).

- **지위**: 제출용 기록. 작성일 2026-09-28, 기준 커밋 `origin/dev` 9093d2e. 제출 뒤에는 소급 수정하지 않는다.
- **정본과의 관계**: 요구사항·설계의 승인 원본은 `aidlc/`에 있다. 이 폴더의 문서는 원본을 평가용으로 다시 엮은 파생본이며, 원본과 어긋나면 원본이 이긴다. 각 문서 끝 「원본과 근거」에 사용한 원본 경로를 적었다.
- **10월판과 12월판**: 10월 MVP판은 승인된 산출물을 기준으로 한다. 12월 계획판은 `docs/ai-dlc-input-december/CatchU_12월_범위_보완.md`(팀장 결정 입력)를 기준으로 한 **미승인 계획**이다. 12월 intent의 요구사항 분석을 거치면 바뀔 수 있다.
- **형식**: Markdown 원고(`NN_*.md`)가 정본이고, `docx/`는 제출용 변환본이다. 다이어그램은 원고의 mermaid 블록이며 GitHub에서 바로 그려진다. docx에는 그림으로 바꿔 넣었고, 그 그림 파일(`images/diagrams/`)은 레포에 올리지 않는다. 화면 그림은 9/23 흑백 와이어프레임 v2.2의 캡처와 9/24 결정에 맞춰 새로 그린 와이어프레임(SVG 원본과 PNG)이다(`images/screens/`, 12월판은 `images/screens12/`).
- **팀원 표기**: 실명으로 적는다. GitHub 이슈·팀 문서의 번호 표기와는 이재민(팀장) = 팀원 1, 이영연 = 팀원 2, 최수영 = 팀원 3, 이채아 = 팀원 4로 대응한다.
