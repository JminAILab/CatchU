# CatchU 12월 승인 문서 안내

12월 목표의 요구사항과 사용자 스토리는 **2026-09-28 승인**됐다. 아래는 팀이 승인 원본을 찾아 읽기 위한 안내다. 요구사항·답변·검토·승인 기록은 `aidlc/`의 원문을 사용한다.

**2026-10-21 후속 결정:** 승인 원본의 일부를 [11월 개발 범위 결정](CatchU_11월_범위_결정.md)이 대체하고, 그 문서의 「프로젝트 목표에서 제외」에 적은 기능은 프로젝트 목표에서 제외했다. 그 문서가 다루지 않은 문의 접수·분석 알림·배포 증거는 재승인 때 확인한다. 이 결정은 11월 전에 요구사항을 재승인해 공식 기준에 반영하며, 11월 기능 구현은 재승인 뒤 시작한다. 그때까지 아래 승인 원본은 당시 기록이자 재승인의 출발점으로 읽는다.

## 적용 범위와 마감

개발 목표의 관계와 확정 산출물의 선반영은 [문서 안내의 「개발 목표와 마일스톤」](README.md#개발-목표와-마일스톤)을 따른다. 아래 10월·12월 계약의 차이는 각 작업에서 적용할 행동을 구분하는 기준이다.

- 10월 MVP 구현은 [10월 승인 요구사항](../aidlc/spaces/default/intents/260914-catchu-october-mvp/inception/requirements-analysis/requirements.md)과 해당 설계·계약을 따른다. 12월 문서 공유만으로 현재 API·ERD나 담당 작업을 변경하지 않는다.
- **링크 정책의 차이:** 10월은 Catch 숨김·확인된 GitHub 저장소 비공개 전환을 기존 링크에도 반영해 해당 Catch의 수신자 열람을 막는다(10월 FR3.4·FR4.1·FR1.5). 12월은 발행 당시 내용을 고정 보존한다([12월 FR4.1·FR4.5](../aidlc/spaces/default/intents/260925-intent-12/inception/requirements-analysis/requirements.md)). 기존 링크를 자동 이관하지 않으며, 배포 준비 시 개발·테스트 데이터 초기화 대상을 확인하고 새 고정 공유본 정책으로 시작한다(같은 문서 C04).
- 12월 문서의 명시적인 정정은 12월 확장 범위의 기준이다. 앞선 승인 문서를 소급 수정하지 않으며, 변경·대체 관계는 요구사항과 답변 기록에서 확인한다.
- 필수 기능 목표는 **11월 30일**, **12월 1~9일**은 추가 검증·수정·제출 준비, 공식 제출은 **12월 10일**이다. 인력·개발량·일정 내 구현 가능성은 미검증이다.
- 팔로우·포스팅·홈 피드, 서비스 내 신고, DM 등 마감 비필수 기능과 후순위 기능, 기업 기능·검색·제안·연락처, 외부 URL 자료 등은 2026-10-21 팀장 결정(10-22 변경)으로 프로젝트 목표에서 제외했다(전체 목록은 [11월 개발 범위 결정](CatchU_11월_범위_결정.md) 「프로젝트 목표에서 제외」). 원문의 당시 지위 기록은 보존한다.
- 위 제외에 따라 마감 비필수·후순위 기능을 팀원이 나누어 AI-DLC로 상세화하던 계획은 진행하지 않는다.

## 승인 원본과 후속 작업

산출물 본문에 남아 있는 ‘작성 기준 확인은 최종 승인이 아니다’ 등의 문장은 작성 당시의 경계를 기록한 것이다. 최종 승인과 이후 정지 여부는 위 승인·정지 기록 및 [상태 파일](../aidlc/spaces/default/intents/260925-intent-12/aidlc-state.md)·[감사 기록](../aidlc/spaces/default/intents/260925-intent-12/audit/macui-macbookpro-local-09cc8fc17dfe.md)을 함께 확인한다.

마지막 완료 단계는 사용자 스토리이고, 도메인 설계 직전에 공식 park했다. 승인 당시의 재개 방침은 **10월 MVP 개발 뒤 도메인·API 계약·ERD 진행**이며, 변경하려면 별도 결정한다. 이번 공유는 후속 설계 재개나 제품 구현·배포 승인이 아니다.

2026-10-21 팀장 결정으로 재개 방식을 정했다. 11월 전에 요구사항 단계부터 AI-DLC로 다시 진행해 [11월 개발 범위 결정](CatchU_11월_범위_결정.md)을 반영한 요구사항·사용자 스토리를 재승인하고, 그 뒤 도메인 설계·API 계약·ERD로 이어간다. 재개할 때는 그 문서의 내용·지위·기준 커밋을 입력에 옮겨 적는다. 2026-10-22·23 변경으로, 재승인 전에 저장소의 AI-DLC를 2.11.1로 올리고 재승인부터 계약 설계·납품 계획까지 팀장이 진행하며, 구현은 AI-DLC 팀 방식으로 한다. 9월 승인 판본과 감사 기록은 고치지 않고 보존한다. 이 결정과 이 문서 수정만으로 정지 상태를 해제하지 않는다.

기존 [12월 입력](ai-dlc-input-december/CatchU_12월_범위_보완.md)은 결정의 출처로 보존한다. 입력 폴더 README의 ‘intent 미시작’ 안내는 승인 전 작성된 설명이며 현재 승인 여부의 근거로 사용하지 않는다.
