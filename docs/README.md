# docs — 문서 정본

이 디렉터리가 팀 문서의 **정본**이 된다.

> **현재 상태**: 문서 이전 진행 중. 완료 전까지는 기존 위치가 정본이다.

## 3층 구조

| 층 | 파일 | 성격 |
|---|---|---|
| 1층 지침 | (개인 AI 도구 설정에 위치) | 불변 원칙 + 느리게 변하는 지식 |
| 2층 정본 | `CatchU_*` | 현행 기준. **`CatchU_현재상태.md`가 진행 상태의 정본** |
| 3층 역사 | `아카이브_*` | 지난 판본. 소급 수정 금지 |

우선순위: **현재상태 > 지침 > 아카이브**

## 규칙

- 문서도 코드와 같은 규칙 — 브랜치 → PR → dev 머지 (브랜치 이름 `docs/파일명`)
- 결정 기록은 **제자리 수정 금지, 추록 누적** — 소급 수정은 판단의 흔적을 지우는 일이다
- 기각된 안도 사유와 함께 남긴다
