# CatchU 개인정보 처리방침

CatchU는 GitHub 작업 기록을 Catch로 정리하고, 고른 Catch와 자료를 링크로 공유하는 서비스입니다. CatchU 팀이 운영합니다. 이 방침은 CatchU가 어떤 개인정보를 왜 받고, 얼마나 보관하고, 누구에게 처리를 맡기는지 설명합니다.

## 1. 처리하는 정보와 목적

| 언제 | 받는 정보 | 쓰는 곳 |
|---|---|---|
| Google로 로그인할 때 | Google 계정 고유 번호 | 회원 구분과 로그인 |
| 프로필을 만들 때 | 표시 이름, 소개, 희망 직무, 기술 | 프로필과 발행본에 표시 |
| GitHub를 연결할 때 | GitHub 계정 번호와 아이디, 접근 정보(암호화해 저장) | 저장소 목록 조회와 분석 |
| 저장소를 분석할 때 | 고른 공개 저장소의 커밋·PR·이슈 기록, 분석 결과와 Catch | Catch 만들기 |
| 자료·JD를 올리고 발행할 때 | 직접 올린 글과 PDF, JD, 발행본과 공유 링크, 발행본의 AI 요약·검색용 색인·JD 요약 결과 | 자료 관리, 발행본 공유, 요약·질의응답·JD 요약 |
| 외부 AI 이용에 동의할 때 | 동의한 고지 판본과 동의 시각 | 동의 확인 |
| Claude를 연결할 때 | 연결 정보(접근 토큰) | 본인이 연결한 Claude에서 본인 자료 읽기 |
| 발행본을 받은 사람이 질문할 때 | 질문 글(저장하지 않음) | 그 질문의 답 만들기 |

- Google에서는 로그인 범위(`openid profile`)만 요청하고 이메일은 받지 않습니다. 처음 프로필을 만들 때 Google 계정 이름을 표시 이름 후보로 보여 주며, 직접 저장할 때만 남습니다. Google이 함께 보내는 다른 값(프로필 사진 주소 등)은 쓰지도 저장하지도 않습니다.
- Google에서 받은 정보는 로그인과 회원 구분에만 쓰고, 다른 곳이나 외부 AI로 보내지 않습니다.

## 2. 보관 기간과 파기

- 회원 정보와 올린 자료, Catch, 발행본은 탈퇴할 때까지 보관합니다. 탈퇴하면 지체 없이 지웁니다(파일 → GitHub 접근 정보 → 회원 정보 순서).
- 올린 글, JD, 발행본은 탈퇴 전에도 하나씩 지울 수 있고, 지우면 바로 삭제합니다. 발행본은 발행할 때의 내용을 따로 담아 두므로, 자료를 지워도 이미 만든 발행본에는 남습니다. 함께 없애려면 그 발행본도 지우거나 링크를 중지해 주세요.
- 분석을 위해 읽은 GitHub 원자료는 분석이 끝나면 지웁니다.
- GitHub 연결을 해제하면 저장해 둔 GitHub 접근 정보를 지웁니다.
- Catch는 하나씩 지우는 기능이 없습니다. 쓰지 않을 Catch는 미공개로 두세요. 받은 사람과 AI 요약·질의응답은 발행한 내용만 봅니다.
- 받은 사람의 질문과 그 답은 저장하지 않고, 서버 기록에도 남기지 않습니다.
- 데이터베이스 자동 백업에는 지운 정보가 최대 7일 남았다가 자동으로 지워집니다. 서버 운영 기록은 14일 뒤 자동으로 지워집니다.
- 법령상 보관해야 하는 항목이 있으면 그 항목만 정해진 기간 동안 따로 보관합니다.
- 지울 때는 데이터베이스와 파일 저장소에서 삭제합니다.

## 3. 제3자 제공

CatchU는 개인정보를 제3자에게 제공하지 않습니다. 다만 본인이 공유 링크를 건넨 사람은 그 발행본을 볼 수 있고, 본인이 연결한 Claude는 본인의 요청에 따라 본인 자료를 읽습니다.

## 4. 처리 위탁과 국외 이전

아래 회사에 처리를 맡깁니다. 외부 AI로 보내는 자료는 해당 기능을 쓸 때마다 암호화된 연결(HTTPS)로 보냅니다.

| 받는 곳(국가) | 맡기는 일 | 보내는 자료 | 받는 곳의 보관 |
|---|---|---|---|
| Anthropic, PBC(미국)<br>privacy@anthropic.com | 저장소 분석의 설명·질문·제목 쓰기, 발행본 기본 요약, 질의응답의 답, JD 요약 | 분석: 본인 커밋에서 바뀐 줄과 파일 경로·상태. 그 밖: 발행본 내용(Catch, 자료 글, PDF에서 뽑은 글), JD에서 나눈 요구 문장, 받은 사람의 질문과 앞선 대화 | AI 학습에 쓰지 않고 최대 30일 안에 지웁니다. 이용 정책 위반으로 자동 표시되면 최대 2년, 법이 요구하면 그 기간 동안 보관될 수 있습니다 |
| OpenAI OpCo, LLC(미국)<br>privacy@openai.com | 저장소 분석에서 AI가 쓴 글이 기록과 맞는지 확인(설정에 따라 이 일을 Anthropic이 대신 맡으면 같은 자료를 Anthropic에 보냄) | Anthropic에 보낸 줄과 파일 경로·상태, 본인 PR 제목이나 커밋 메시지 첫 줄, AI가 쓴 제목 후보와 설명 문장 | AI 학습에 쓰지 않습니다. 남용 감시 기록에 최대 30일 보관되며, 법이 요구하거나 서비스·다른 사람을 해로부터 지키는 데 필요하면 더 오래 보관될 수 있습니다 |
| Voyage AI Innovations, Inc.(MongoDB 계열, 미국)<br>contact@voyageai.com | 발행본 검색을 위한 변환(임베딩) | 발행본 내용 조각, 받은 사람의 질문, JD 요약에 쓰는 JD 요구 문장 | AI 학습에 쓰지 않고 처리 직후 지웁니다 |
| Amazon Web Services(AWS, 서버는 대한민국 서울 리전) | 서버 운영, 데이터베이스·파일 보관 | CatchU가 보관하는 정보 전체 | CatchU의 보관 기간(2번)을 따릅니다 |

- 외부 AI 이용 동의는 처음 한 번 받습니다. 동의하지 않으면 발행(발행본에 AI 요약과 질의응답이 붙기 때문)과 JD 요약을 할 수 없고, 자료 올리기와 프로필 같은 다른 기능은 그대로 쓸 수 있습니다.
- 저장소 분석은 분석할 때마다 따로 동의를 받습니다. 동의하지 않으면 그 분석만 접수되지 않습니다.
- 받은 사람의 질문은 질문을 보낼 때만 외부 AI로 갑니다.
- 올린 자료는 이름·연락처를 가리지 않고 그대로 보냅니다. 보내기 전에 민감한 정보를 지워 주세요. 저장소 분석에서는 이메일·접근 토큰처럼 보이는 값을 자동으로 가린 뒤 보내지만, 모든 값을 찾지는 못합니다.

## 5. 이용자의 권리와 행사 방법

- 보기·고치기: 프로필 화면에서 본인 정보를 보고 고칠 수 있습니다.
- 하나씩 지우기: 올린 글, JD, 발행본은 각 화면에서 지울 수 있습니다.
- 처리 멈추기: Catch 미공개로 두기, 공유 링크 중지, GitHub·Claude 연결 해제로 할 수 있습니다. 외부 AI 이용 동의를 하지 않으면 AI로 자료를 보내지 않습니다.
- 지우기: 탈퇴하면 2번대로 지웁니다.
- 그 밖의 요청은 8번 문의처로 보내 주세요.

## 6. 쿠키와 브라우저 저장

- 로그인을 유지하는 쿠키 하나만 씁니다. 광고·분석용 쿠키나 외부 분석 도구는 쓰지 않습니다.
- 로그인 진행 정보와 비밀번호 링크 확인 표시는 브라우저 탭 저장소에만 두며, 탭을 닫으면 사라집니다.
- 브라우저에서 쿠키를 막으면 로그인이 유지되지 않습니다.
- 비밀번호가 걸린 링크를 열 때는 접속 주소(IP)를 시도 횟수를 세는 데만 서버 메모리에서 잠깐 쓰고 저장하지 않습니다. 앞단 방화벽(AWS WAF)도 지나친 요청을 막는 데 접속 주소를 씁니다.

## 7. 안전 조치

- 모든 연결은 암호화된 연결(HTTPS)만 씁니다.
- GitHub 접근 정보는 암호화해 저장하고, 데이터베이스는 저장 암호화를 켜 둡니다.
- 공유 링크 비밀번호는 원문을 저장하지 않고, 되돌릴 수 없게 바꾼 값(해시)만 저장합니다.
- 서버와 데이터베이스에 접근할 수 있는 사람은 운영 담당 한 명으로 제한합니다.
- 비밀값은 코드와 분리해 별도 보관소에 둡니다.
