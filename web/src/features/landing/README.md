# 비로그인 서비스 소개 (`/`, #384·#395)

비로그인 사용자가 처음 보는 소개 화면이다. 서비스 안내, 가상 Catch 예시, 로그인 진입을 보여 준다. 외형은 #384·#395(leechaeah), 문구 리뷰와 로그인 이동 확인은 csyg0616이 맡는다([#155 합의](https://github.com/JminAILab/CatchU/issues/155#issuecomment-6354442095)).

## 근거

- [홈 흐름 초안](../../../../docs/ai-dlc-input-mvp/CatchU_서비스홈_흐름_와이어프레임_초안.md) §5.2 「비로그인 홈 — 소개·가상 예시·Google 시작」과 §6.1의 [Google로 시작하기] 동작. 초안의 문구·배치는 제안 지위 그대로다.
- 단계 설명은 10월 기능 흐름(기록 → Catch 확인 → 공개 선택 → 링크 공유)을 따른다. 독립 강점 주장·서류 첨부는 10월 범위가 아니라 넣지 않는다.
- 배치와 움직임은 지난 시안(v7)을 참고했고, 문구는 시안이 아니라 #391에서 확인한 것을 쓴다.

## 구성

가운데 정렬 제목 → 겹친 카드 3장 → 스크롤로 들어오는 장면 4개 → 마무리 순서다.

### 자유 스크롤 시안 디자인 (#457)

2026-11-02 사용자의 적용 요청으로 `1안(자유 스크롤) (2).zip` 안 `CatchU-intro-20261013`의 색·Pretendard 글꼴·로고·여백·그림자·상세 카드 구성을 옮겼다. 기존 #399에서 제외했던 시각 요소를 소개 화면에 한정해 적용한다.

- 원본 HTML을 React JSX와 CSS Modules로 옮겼다. 시안 JavaScript·로그인 대역·검토용 배너를 실행하거나 HTML 문자열을 주입하지 않는다.
- 소개의 헤더는 `LandingPage`가 그린다. 공통 `GuestHeader`는 `/`에서만 생략하고 로그인·콜백 화면에서는 기존 헤더를 유지한다. 로그인 버튼은 `/login`으로 이동한다.
- 원본 글꼴의 데이터 URL을 `public/landing/PretendardVariable.woff2`로 분리해 같은 출처에서 제공한다. 로고도 같은 폴더에 두고, 글꼴의 SIL OFL 라이선스는 `Pretendard-OFL.txt`에 보존한다. 외부 글꼴·이미지 서비스는 호출하지 않는다.
- 시안의 시각적 구성 안에 기존 제품 의미를 유지했다. 히어로 오른쪽 카드는 본인만 보는 질문, 세 번째 장면은 사실·기여 확인과 별도 공개 선택, 네 번째는 공개 Catch·비밀번호 선택·링크 열람이다. 시안의 독립 강점 주장·PDF 등록 기능은 추가하지 않는다.
- 원본 미리보기 PNG는 이전 스크롤 방식의 버튼을 포함하므로 실제 ZIP의 HTML/CSS를 디자인 대조 기준으로 삼는다.

## 스크롤과 움직임

- 스크롤은 브라우저 기본 그대로이며 장면을 붙잡거나 넘기지 않는다.
- 히어로는 시안의 겹친 카드 배치를 사용한다. 장면 카드는 `reveal.tsx`가 화면에 66% 이상(낮은 창에서는 창 높이의 66%) 보일 때 0.9초 동안 한 번 조립한다. 걸쳐만 있으면 1.2초 뒤, 이미 지나쳤으면 바로 보여 준다.
- 숨김은 `reveal.tsx`가 브라우저에서 켠 뒤에만 적용된다. JavaScript가 꺼져 있거나 움직임 줄이기 설정, 폭 760px 이하, IntersectionObserver 미지원이면 처음부터 모두 보인다. 인쇄 때도 모두 보인다.
- 760px 이하에서는 카드가 겹치지 않고 세로로 쌓인다.

## 지키는 것

- [Google로 시작하기]는 헤더와 같은 `/login`으로만 이동한다. 로그인·분석·동의·공개를 이 화면에서 실행하지 않는다.
- 가상 예시는 고정 문구이며 실제 사용자·저장소·커밋 주소를 쓰지 않는다. 누를 수 있는 동작이 없고, 실제 카드처럼 보이지 않게 「가상 예시」 표시와 안내를 둔다.
- 서버 조회·브라우저 저장·외부 서비스 자원을 쓰지 않는다. 소개 전용 색·폭·글꼴은 `landing.module.css`의 `.page` 범위에 두고, 다른 화면의 `globals.css` 공통 테마는 바꾸지 않는다.

## 검사

- `npm run check`의 `check:run`이 `/` 본문의 `id="landing-title"`로 이 화면이 그려졌는지 확인한다.
- 문구·배치 변경은 낮은 창(높이 420px 안팎)과 320~1440px 폭에서 가로 넘침과 겹침, 키보드 Tab으로 [Google로 시작하기]에 닿고 Enter로 `/login`에 가는지 브라우저로 확인한다.
