# 비로그인 서비스 소개 (`/`, #384)

비로그인 사용자가 처음 보는 소개 화면이다. 서비스 안내, 가상 Catch 예시, 로그인 진입을 보여 준다. 외형은 #384(leechaeah), 문구 리뷰와 로그인 이동 확인은 csyg0616이 맡는다([#155 합의](https://github.com/JminAILab/CatchU/issues/155#issuecomment-6354442095)).

## 근거

- [홈 흐름 초안](../../../../docs/ai-dlc-input-mvp/CatchU_서비스홈_흐름_와이어프레임_초안.md) §5.2 「비로그인 홈 — 소개·가상 예시·Google 시작」과 §6.1의 [Google로 시작하기] 동작. 초안의 문구·배치는 제안 지위 그대로다.
- 단계 설명은 10월 기능 흐름(기록 → Catch 확인 → 공개 선택 → 링크 공유)을 따른다. 독립 강점 주장·서류 첨부는 10월 범위가 아니라 넣지 않는다.

## 구성

| 영역 | 내용 |
|---|---|
| 소개 | 제목·Catch 정의·분석이 하는 일, [Google로 시작하기] |
| 가상 예시 Catch | 「가상 예시」 표시, 작업에서 확인된 사실·Catch 설명 초안·근거·생각해 볼 질문(「본인만 확인」), 실제 분석 결과가 아니라는 안내. 항목 이름은 실제 Catch 상세와 같다 |
| 순서 | 4단계 목록 |
| 마무리 | 한 줄 안내와 [Google로 시작하기] |

## 지키는 것

- [Google로 시작하기]는 헤더와 같은 `/login`으로만 이동한다. 로그인·분석·동의·공개를 이 화면에서 실행하지 않는다.
- 가상 예시는 고정 문구이며 실제 사용자·저장소·커밋 주소를 쓰지 않는다. 누를 수 있는 동작이 없고, 실제 카드처럼 보이지 않게 「가상 예시」 표시와 안내를 둔다.
- 서버 조회·브라우저 저장·외부 자원(이미지·글꼴·스크립트)을 쓰지 않는다. 색·폭·글꼴은 `globals.css` 공통 변수를 쓰고, 이 화면에서만 쓰는 보조 색은 `landing.module.css`의 `.page`에 둔다.

## 검사

- `npm run check`의 `check:run`이 `/` 본문의 `id="landing-title"`로 이 화면이 그려졌는지 확인한다.
- 문구·배치 변경은 데스크톱·모바일 폭에서 가로 넘침과 겹침, 키보드 Tab으로 [Google로 시작하기]에 닿고 Enter로 `/login`에 가는지 브라우저로 확인한다.
