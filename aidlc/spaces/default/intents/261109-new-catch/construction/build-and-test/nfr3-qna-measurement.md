## AC8.1.2 기본 요약 — 불충족

같은 발행본의 기본 요약은 발행 때 이미 만들어져 있어(DONE, 6항목) 새로 만들지 않고 그것을 봤다.

- 꼴: 작성자 설명에서 온 4문장은 모두 「작성자는 …라고 적었다」 꼴이다(4/4).
- 딱지: 6항목이 모두 인용 없는 AI 해석 항목이라 '작성자 자료 원문' 딱지가 붙지 않는다. 요약 항목 형식의 문제다.
- 항목 5는 GitHub 기록(커밋 메시지)을 작성자 주장처럼 썼다.

팀장 결정(2026-11-12): 고치지 않고 「불충족」으로 기록한다. 이 기록과 NC3 PR 「수행하지 못한 검증」에 남기고 intent가 끝난 뒤 후속으로 다룬다.
