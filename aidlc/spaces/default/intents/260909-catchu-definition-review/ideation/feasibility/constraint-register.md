# CatchU 제약 목록

## 상태를 읽는 기준

확정된 요청·결정, 계획 기준, 현재 확인한 사실, 잠정 기대·선호, 미확인 조건을 구분한다. 이 목록은 확정 제약만 모은 표가 아니며, 기술 후보나 제공 지역 구상을 필수 조건으로 승격하지 않는다. 요약 확인 이후 작성한 검토 산출물로서 단계 승인은 별도다. 평가의 근거·한계는 [실현 가능성 평가](feasibility-assessment.md)에 정리했다. [IC] [Q]

## Assumptions & Open Questions

확인되지 않은 항목에 채택한 수치 기본값은 없다. 상세 미결은 [평가의 FE-OQ1~FE-OQ7](feasibility-assessment.md#assumptions--open-questions)을 사용한다. 대응 관계는 다음과 같다.

- 공개 정책·기능 수준: C03·C04·C07·C08 → FE-OQ1.
- 역할·실제 가용량: C05·C06·C07 → FE-OQ2.
- PoC 적합성: C09·C15 → FE-OQ3.
- 자원·기술 준비: C08·C10·C11 → FE-OQ4.
- 이용량·비용: C08·C12·C14 → FE-OQ5.
- 대한민국 우선 구상과 실제 데이터 처리: C13~C16 → FE-OQ6.
- 검증 기준: C17 → FE-OQ7.
