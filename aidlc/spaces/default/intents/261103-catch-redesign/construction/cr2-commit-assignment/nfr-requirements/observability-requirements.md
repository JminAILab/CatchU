# CR2 소속 저장 — 관측 요구사항

입력: CR2 기능 설계(`functional-spec.md` W6), 이 단계의 답 `nfr-requirements-questions.md`(Q2 B), 지금 코드(`worker/app/candidates/build.py`의 후보 판정 로그 「후보 판정 종료」).

| ID | 요구사항 | 확인 기준 |
|---|---|---|
| NFR4.5 | worker의 후보 판정 종료 로그 한 줄에 숫자 두 개를 더한다: 받은 소속 SHA 수(`assignedShas`), 소속으로 버린 단위 수(`assignedUnits`). 결과가 빈 재분석이 「모두 이미 소속」인지 다른 이유인지 이 줄로 구분한다. SHA 자체는 남기지 않는다. | 시험: 소속 단위를 버린 요청의 로그 줄에 두 숫자가 맞게 있고, 40자 16진수가 없다. |

## 정하지 않는 것

- 새 지표·경보·대시보드는 두지 않는다. 지금 운영 로그 수집으로 본다.
- api 쪽에 새 로그를 더하지 않는다. 소속 쓰기 실패는 지금 반영 실패 기록에 들어간다.
