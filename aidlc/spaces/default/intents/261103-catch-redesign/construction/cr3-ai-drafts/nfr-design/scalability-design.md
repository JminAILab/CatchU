# CR3 AI 쪽 — 확장성 설계

입력: 비기능 요구사항 NFR2.4·NFR4.1, 기능 설계 BR6.2.

- **질문 상한 지키기(NFR2.4):** 재료 판정 요청 조립은 CR1 규칙 순서로 파일을 늘어놓고, 파일 하나의 질문(갈래·묶음·점수 가운데 해당하는 것)을 통째로 더할 수 있을 때만 그 파일을 담는다. 400개를 넘기면 거기서 멈추고, 남은 파일은 판정 없음으로 표시한다. 파일의 질문 일부만 담지 않는다.
- **경계에 손대지 않기(NFR4.1):** 판정 구성 요소는 후보 판정(CandidateGrouping)의 결과를 읽기만 하고, 열쇠·근거·소속을 고치는 함수를 부르지 않는다. 판정 답이 바꾸는 것은 제목·설명·재료 순서·작업 사실 둘째 줄 지우기뿐이다.
- **서버 쪽:** worker 동시 처리 수·큐·저장은 바꾸지 않는다.
