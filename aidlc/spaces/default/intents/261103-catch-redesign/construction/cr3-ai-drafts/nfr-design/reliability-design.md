# CR3 AI 쪽 — 신뢰성 설계

입력: 비기능 요구사항 NFR2.5·NFR3.1, 기능 설계 BR2.2·BR2.5·BR2.6·BR3.5·BR5.4·BR6.4.

## 실패 나누기 (NFR2.5)

판정 어댑터는 공급자 오류를 셋으로 바꿔 올린다. 생성 어댑터의 나누기와 같은 모양이다.

| 경우 | 실패 코드 | 다시 시도 |
|---|---|---|
| 시간 초과 | JUDGEMENT_TIMEOUT | 없음 |
| 호출 오류(연결·인증·429·5xx) | JUDGEMENT_CALL_FAILED | 없음 |
| 읽을 수 없는 응답·크기 초과 | JUDGEMENT_RESPONSE_UNREADABLE | 없음 |

- Catch 판정 실패: 설명 FAILED(실패 항목 단계 DRAFT, 위 코드), 제목·둘째 줄은 판정 없음.
- 재료 판정 실패: 실패 항목을 남기지 않고(설명 결과에 영향 없음) 운영 로그 건수에만 센다. 재료는 CR1 규칙 순서다.
- 서킷 브레이커는 두지 않는다. 호출 상한(300번)과 마감이 한 분석 안의 실패 비용을 묶는다.

## 켜고 끄기 (NFR3.1)

- 켜는 판단은 기동 때 한 번 하고, 분석 도중 바뀌지 않는다.
- FR10을 못 넘으면 배포 설정에 판정 키와 `claude` 공급자 값을 넣지 않는다. 코드는 꺼진 경로가 CR1과 같은 결과를 낸다(BR1.3).
- 운영에서 끄려면 공급자를 `openai`로 두거나 지우고 판정 키를 비운 뒤 worker를 다시 띄운다.
