# Catch 개편 — 바깥 의존

Bolt는 Unit 하나를 기능 설계부터 시험까지 지나 실제로 돌아가는 결과로 끝내는 구현 묶음이다. 아래는 AI 구현 밖에서 와야 하는 것과 그것이 막는 Bolt다.

| 의존 | 주인 | 걸리는 시간 | 막는 Bolt | 늦어지면 |
|---|---|---|---|---|
| 12월 intent의 통합 확인(통합 브랜치에 넣는 조건, 입력 §8-6) | 팀장(12월 intent) | 11/13 1차 통합 확인 예정 | B1·B2·B3의 PR 넣기(구현은 막지 않음) | 작업 브랜치에서 계속하고 확인 뒤 PR을 낸다 |
| OpenAI 판정 키를 SSM·EKS에 넣기(NFR5) | 팀장(공유 인프라) | 실측 없음(키 발급·SSM 반영) | B2의 AI 쪽 켜기와 FR10 실제 판정 | 합성 판정으로 구현·시험을 계속하고, FR10 확인만 미룬다. 기준을 못 재면 AI 쪽을 끈 채 합친다 |
| OpenAI 회사 이름·연락처 공식 안내 확인(FR9.1) | 팀장 | 실측 없음 | B2의 고지 v3 문구 | 고지 v3 PR을 미룬다. AI 쪽은 고지와 함께만 켠다 |
| 고지 v3·첫 이용 고지 문구 승인(FR9) | 팀장(PR 리뷰) | PR마다 | B2의 AI 쪽 켜기 | AI 쪽을 끈 채 합친다 |
| FR10 확인용 Catch 20개 표시(CatchU 6·TheMe 7·algo-problem 7) | 팀장 | 실측 없음 | B2 완료 | 기준 판정이 없으면 AI 쪽을 켜지 않는다 |
| 출시 직전 DB 초기화 날짜 | 팀장 | 날짜 미정 | B3의 시한 | B3 PR을 초기화 전에 넣는다. 날짜가 정해지면 시한을 그 날짜로 둔다 |

- Claude API 키와 GitHub 연결은 이미 있다. 그래서 바깥 의존으로 두지 않는다.
- U7 분석 고지 v2(#433)는 11/2에 통합 브랜치에 병합되었다. 고지 v3는 그 위에서 고친다.
