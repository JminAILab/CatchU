# Catch 개편 — 의도 설명

이 작업은 이슈 #445 「Catch 개편」이다. [desc]

## Problem Statement

두 문제를 함께 푼다. [Q1]

- **중복 Catch:** 재분석은 경계를 매번 다시 계산한다. 그래서 범위가 밀리거나 새 커밋이 붙으면 같은 작업이 중복 Catch가 된다. [Q1]
- **읽히지 않는 Catch:** 「CreateArticlePage.vue 코드 수정」 같은 제목과 「PR 없이 병합한 병합 커밋 f0b728b28882」 같은 작업 사실로는 무슨 작업인지 알 수 없다. 12월 받은 사람 AI가 읽는 근거에도 작성자 설명 말고는 "무엇을 했나"가 없다. [Q1]
