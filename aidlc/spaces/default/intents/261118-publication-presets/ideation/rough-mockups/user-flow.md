# User Flow — 발행 프리셋

근거: 승인된 의도 진술 `ideation/intent-capture/intent-statement.md`(intent-statement), 범위 문서 `ideation/scope-definition/scope-document.md`(scope-document), 백로그 `ideation/scope-definition/intent-backlog.md`(intent-backlog), `wireframes.md`(W1~W6), 이 단계 질문의 답(Q1~Q7).

## 전체 흐름

```
[지원자] 상단 메뉴 「프리셋」(W1) --> 프리셋 목록(W2) --[새 프리셋]/<고치기>--> 프리셋 편집(W3)
                                                                                  |
                                                                              [저장]
                                                                                  v
[지원자] 발행본(W1) --[새로 발행]--> 발행(W4): 프리셋 고르기 -> 순서 -> 제목과 비밀번호 -> 발행 내용 확인 -> 발행됨
                                                                                  |
                                                                         링크를 면접관에게 보냄
                                                                                  v
[면접관] 받은 사람 화면(W5): AI 요약 -> 탭으로 자료 보기 -> 발행본에 질문하기 -> [출처] -> 해당 탭의 글 -> [답으로 돌아가기]
```

## F1. 프리셋 만들기

```
Flow: 프리셋 만들기
Persona: 지원자
Trigger: 상단 메뉴의 「프리셋」(W1), 또는 발행 화면(W4)에 프리셋이 없을 때 보이는 프리셋 화면 링크
Steps:
  1. 프리셋 목록(W2) -> [새 프리셋] -> 프리셋 편집(W3)이 빈 채로 열림
  2. 프리셋 편집 -> 이름을 쓴다 -> 이름 칸에 보임
  3. 프리셋 편집 -> 담을 자료 고르기에서 Catch·텍스트 자료·PDF를 고른다 -> 「담긴 자료와 순서」에 더해지고 항목 수·글자 수가 바뀜. 비공개·확인 필요 Catch는 표시가 붙음
  4. 프리셋 편집 -> [위로]·[아래로]로 순서를 정한다 -> 순서가 바뀜
  5. 프리셋 편집 -> [저장] -> 저장되고 프리셋 목록에 보임
Success outcome: 프리셋 목록에 새 프리셋이 이름·항목 수·글자 수와 함께 보인다
Error paths:
  - 저장 실패 -> 실패 안내 -> 입력은 그대로, 다시 [저장]
  - 목록 불러오기 실패 -> 실패 안내와 [다시 불러오기] -> 0개로 보이지 않음
```

## F2. 프리셋 고치기·지우기

```
Flow: 프리셋 고치기·지우기
Persona: 지원자
Trigger: 프리셋 목록(W2)의 <고치기>
Steps:
  1. 프리셋 편집(W3) -> 이름·담긴 자료·순서를 고친다 -> 「프리셋을 고쳐도 이미 보낸 링크는 바뀌지 않습니다」 안내가 보임
  2. 프리셋 편집 -> [저장] -> 저장됨
  3. (지우기) 프리셋 편집 -> [프리셋 지우기] -> 프리셋 이름을 밝힌 확인 -> 지워지고 프리셋 목록으로
Success outcome: 바뀐 프리셋이 목록에 보인다. 이미 보낸 발행본은 바뀌지 않는다
Error paths:
  - 저장 실패 -> 실패 안내 -> 입력은 그대로
  - 지우기 확인에서 취소 -> 편집 화면 그대로
```

## F3. 프리셋으로 발행

```
Flow: 프리셋으로 발행
Persona: 지원자
Trigger: 발행본 화면(W1)의 [새로 발행]
Steps:
  1. 발행(W4) 「프리셋 고르기」 -> 프리셋을 고른다(최대 5개) -> 「고른 프리셋과 순서 (n/5)」에 더해짐
  2. 「고른 프리셋과 순서」 -> [위로]·[아래로]로 순서를 정한다 -> 순서가 바뀜
  3. 「제목과 비밀번호」 -> 지금처럼 입력 -> [다음: 발행 내용 확인]
  4. 「발행 내용 확인」 -> 제목·비밀번호·만료와 고른 프리셋·순서를 확인 -> [발행]
  5. 「발행됨」 -> 링크 주소가 보임(지금 그대로)
Success outcome: 발행본이 만들어지고 링크를 보낼 수 있다
Error paths:
  - 프리셋 목록 불러오기 실패 -> 실패 안내와 [다시 불러오기] -> 「프리셋 없음」으로 보이지 않음
  - 프리셋이 없음 -> 「프리셋 고르기」 자리에 프리셋 화면을 가리키는 링크만 보임 -> F1로
  - 6개째를 고르려 함 -> 최대 5개라는 안내(세부는 요구사항 단계)
  - 발행이 막힘(확인이 필요한 Catch 등) -> 어느 프리셋의 어느 자료 때문인지 보임 -> 프리셋 편집(W3)에서 고친 뒤 다시 발행
```

## F4. 면접관이 발행본 읽기

```
Flow: 받은 발행본 읽기
Persona: 면접관
Trigger: 지원자가 보낸 링크를 연다
Steps:
  1. 받은 사람 화면(W5) -> 제목·안내·Claude 연결·발행 시각 다음에 「AI 요약」을 읽는다
  2. 「발행본 자료」의 탭 줄 -> 탭을 누르거나 화살표 키로 옮긴다 -> 그 프리셋의 자료와 프리셋 이름 전체가 보임
  3. 「발행본에 질문하기」 -> 질문한다 -> 답이 보임. 탭을 바꿔도 대화는 남음
  4. 답이나 요약의 [출처] -> 가리킨 글이 다른 탭에 있으면 그 탭으로 바뀌고 그 글로 옮겨 가 강조됨, 바로 위에 [답으로 돌아가기]. 가리킨 글이 지금 탭에 있어도 [답으로 돌아가기]가 보임
  5. [답으로 돌아가기] -> 답에서 눌렀으면 그 답으로, 요약에서 눌렀으면 요약으로 돌아감. 초점은 눌렀던 출처 단추에. 탭은 옮겨 간 탭 그대로
Success outcome: 면접관이 프리셋별로 자료를 구분해 읽고, 요약·답의 출처를 확인한다
Error paths:
  - 링크를 쓸 수 없음(중지·만료·비밀번호) -> 지금 화면 그대로
  - 발행본 불러오기 실패 -> 지금 화면 그대로
```

## F5. 작성자가 자기 발행본 보기

```
Flow: 발행본 상세 보기
Persona: 지원자
Trigger: 발행본 목록(W1)에서 발행본을 연다
Steps:
  1. 발행본 상세(W6) -> 「발행본 자료」가 W5와 같은 탭 줄로 보임 -> 탭으로 프리셋별 자료를 본다
  2. AI 요약의 [출처] -> F4의 4~5단계와 같이 다른 탭의 글로 옮겨 가고 [답으로 돌아가기]로 돌아온다
Success outcome: 면접관이 보는 것과 같은 탭 구분으로 자기 발행본을 확인한다
Error paths:
  - 지금 상세 화면 그대로
```

## F6. 프리셋에 담긴 자료 지우기

```
Flow: 프리셋에 담긴 텍스트 자료·PDF 지우기
Persona: 지원자
Trigger: 텍스트 자료 화면에서 텍스트 자료나 PDF를 지운다
Steps:
  1. 지우기 확인 -> 그 자료가 프리셋에 담겨 있으면 거기서도 빠진다는 말이 보임 -> 지우기를 확인한다
  2. 자료가 지워지고 담겨 있던 프리셋에서 자동으로 빠짐 -> 프리셋 목록(W2)의 항목 수·글자 수가 바뀜
Success outcome: 지운 자료는 어느 프리셋에도 남지 않는다. 이미 보낸 발행본은 바뀌지 않는다
Error paths:
  - 지우기 확인에서 취소 -> 자료와 프리셋 그대로
```

탈퇴는 화면 변경이 없고 탈퇴할 때 프리셋도 지운다. 개인정보처리방침은 문구만 바뀐다.

## 정보 구조

```
텍스트 자료 (상단 메뉴, 지금 그대로, 탭이 화살표 키로도 옮겨짐)
프리셋 (상단 메뉴, 새로, 「텍스트 자료」와 「발행본」 사이) -> 프리셋 목록 (W2)
  - 프리셋 편집 (W3, 새로)
발행본 (상단 메뉴, 지금 그대로)
  - 내 발행본 목록 (W1)
      - 발행본 상세 (W6)
  - 새로 발행 -> 발행 (W4)
받은 링크 -> 받은 사람 화면 (W5)
```

## Assumptions & Open Questions

- 항목이 0개인 프리셋을 발행 화면에서 고를 수 있는지: 요구사항 단계.
- 출처로 옮겨 간 직후 초점이 놓이는 자리와 [답으로 돌아가기]에 키보드로 닿는 방법: 다듬은 화면 단계.
- 저장하지 않은 변경을 두고 프리셋 편집 화면을 떠날 때의 처리: 다듬은 화면 단계.
