## Q1. [설계] 프리셋을 맡을 구성 요소와 「발행할 수 있는가·글자 수」 규칙의 자리

프리셋 저장·목록·지우기와, 목록에 보일 항목 수·글자 수·발행할 수 없는 자료(FR1.2, FR1.11, FR1.14)를 누가 맡는지 정해야 합니다. 이 판정과 글자 세기는 지금 발행 쪽에 있고, 발행은 고른 프리셋을 읽어야 하므로 두 쪽이 서로 기대게 됩니다.

A. 프리셋을 발행 모듈(api `publications`) 안에 둔다. 설계에서는 프리셋을 따로 된 구성 요소로 적지만, 코드는 같은 모듈에서 지금 판정·글자 세기 함수를 그대로 쓴다. 가장 단순하다. 발행 모듈 파일이 늘어난다
B. 새 프리셋 모듈(api `presets`)을 두고, 「발행할 수 있는가·글자 수」 규칙을 발행 모듈에서 떼어 두 쪽이 함께 쓰는 작은 구성 요소로 옮긴다(발행 → 프리셋, 발행·프리셋 → 규칙, 서로 부르는 고리 없음). 발행 모듈이 커지지 않고 프리셋 코드가 발행 내부 변경에 덜 휘말린다. 대신 규칙 함수와 공개 자격 확인 SQL을 옮기고 모듈 연결을 더하는 공수가 는다
C. 새 프리셋 모듈이 발행 모듈의 판정 함수를 가져다 쓰고, 발행은 프리셋 표를 SQL로 직접 읽는다(지금 발행이 Catch·자료 표를 읽는 방식). 모듈을 서로 부르지는 않지만 서로의 내부에 기댄다
X. Other (please specify)

## Q2. [설계] 발행 요청에 무엇을 실을까

서버가 발행할 때 고른 프리셋과 자료를 다시 확인하고 막히면 어느 프리셋의 어느 자료 때문인지 알려야 하고(FR2.8), 프리셋은 그 지원자의 것만 받아야 하며(NFR2), 사본에는 발행 당시 프리셋 이름을 복사합니다(FR2.11).

A. 프리셋 ID 목록(1~5개, 고른 순서)만 싣는다. 서버가 발행 트랜잭션 안에서 프리셋을 읽어 자료로 펴고 이름을 사본에 복사한다. 막히면 응답에 프리셋 ID와 자료를 실어 web이 그대로 보인다(오류 응답이 옮기는 칸 하나를 더함)
B. web이 고른 프리셋을 펴서 항목 목록과 묶음(이름·항목 수)을 보낸다. 서버는 프리셋을 모르고 지금 검사를 그대로 쓰며, 막힘은 지금 응답(Catch ID, 요청 위치)으로 web이 되짚는다. 서버가 「고른 프리셋이 본인 것이고 지금 내용과 같은가」를 확인하지 못해 FR2.8·NFR2와 맞지 않는다

## Q3. [설계] 발행본 사본에 프리셋 구분을 어디에 저장할까

받은 사람 화면과 작성자 상세가 탭을 그리려면 사본에 프리셋 순번과 발행 당시 이름이 있어야 합니다(FR2.11, FR3.2). 항목 순서 번호는 발행본 전체에 이어 매깁니다(FR6.1).

A. 발행본 항목 표(`published_item`)에 칸 둘(프리셋 순번 1~5, 발행 당시 프리셋 이름)을 더한다. 항목이 0개인 프리셋은 고를 수 없어(FR2.4) 모든 탭에 항목이 있으므로 항목만으로 탭을 만들 수 있다. 이름이 항목마다 되풀이된다
B. 새 표(발행본, 프리셋 순번, 이름)를 두고 항목 표에 순번 칸을 더한다. 짝을 외래 키가 지킨다. 표·마이그레이션이 하나 늘고 사본 읽기가 두 표를 읽는다
C. 발행본 표(`publication`)에 jsonb 칸 하나(순번별 이름과 항목 수)를 더한다. 칸은 하나지만 항목과의 짝을 DB가 지키지 않는다
X. Other (please specify)

[Answer]: A

## Q4. [설계] 프리셋 안 자료가 원본을 가리키는 방식

텍스트 자료나 PDF를 지우면 담긴 프리셋에서도 빠지고(FR4.1), 탈퇴하면 프리셋도 지워집니다(FR4.2). 담은 뒤 숨긴 Catch는 프리셋에 남기고 이유를 보입니다(FR1.11).

A. 프리셋 항목 행에 종류별 외래 키 칸 셋(Catch·텍스트 자료·PDF 가운데 하나만 채움, 원본을 지우면 연쇄 삭제)을 둔다. 자료를 지우면 DB가 프리셋에서 저절로 빼므로 자료 모듈 코드는 그대로 두고 화면 확인 문장만 바꾼다. 프리셋 표는 회원 행에 연쇄 삭제로 묶어 탈퇴 코드도 그대로 둔다
B. 종류 + 원본 ID 한 쌍(외래 키 없음, 발행 사본과 같은 모양)으로 가리킨다. 자료를 지울 때 자료 모듈이 프리셋 항목도 지워야 하고, 빠뜨리면 없는 자료가 프리셋에 남는다
X. Other (please specify)

[Answer]: A

## Q5. [설계] 프리셋 목록·편집 화면의 항목 수·글자 수·발행할 수 없는 자료를 언제 셀까

B. 프리셋을 저장할 때 세어 함께 저장한다. 원본이 바뀌면(FR1.11, FR1.14) 값이 틀려지므로 다시 세는 장치가 더 필요하다
