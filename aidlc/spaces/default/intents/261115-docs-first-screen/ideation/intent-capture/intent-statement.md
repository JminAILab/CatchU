# 의도: 첫 화면 문서를 지금 CatchU 기준으로 고치기

이 작업은 #552의 첫 화면 문서(루트 README, docs/README, '지금 CatchU' 요약)를 지금 CatchU 기준으로 고친다. [desc]

## 풀려는 문제

- 루트 `README.md`와 `docs/README.md`가 9~10월 설명(증거카드·양면 플랫폼)과 8~9월 설계 문서로 이어져, 처음 보는 사람이 지금 CatchU를 알 수 없다. [Q1]
- 지금 CatchU는 지원자가 골라 면접관에게 보내는 Catch 한 장이다. [Q1]
- 지금 제품을 한 번에 설명하는 글이 없다. [Q1]
- 문서에서 Catch를 받아 보는 쪽은 「면접관」으로 부르고, 「팀장」은 intent를 정하는 우리 팀장만 뜻하게 쓴다. [memory:M1]

## 읽는 사람

- 이 저장소는 팀원의 포트폴리오다. [Q9]
- 첫 독자는 팀원의 포트폴리오로 이 저장소를 여는 면접관이다. [Q9]
- CatchU로 이 저장소를 분석해 보는 사람은 그다음 독자다. [Q9]
- 면접관이 첫 화면에서 더 알아야 할 것은 여기서 정하지 않고 요구사항 단계에서 질문으로 올린다. [Q9]
- 팀원과 각자의 AI가 읽는 지침은 이 작업의 독자로 두지 않는다. [Q2]
