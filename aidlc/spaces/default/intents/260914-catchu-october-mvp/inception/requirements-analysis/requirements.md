## 의도 분석

구직자는 동의한 선정 공개 저장소의 실제 기록에서 경험 후보·근거·짧은 Catch 설명 초안과 최소 생각해볼 질문을 확인한다. 본인이 확인한 자료를 별도로 공개하고 링크로 전달하며, 비로그인 수신자는 현재 허용된 자료를 읽는다. 실제 결과의 연결·권한·실패 처리·자료 보존·NCP 수동 배포/복구 증거까지가 첫 MVP 목표다. 기존 저장분·모의 응답·최소 연결 성공만으로 완료를 대신하지 않는다. [I, S, H]

핵심 흐름: 로그인/미연동 홈 → GitHub 연동 → 자산 GitHub 탭의 대상 선택·분석 동의 → 실제 분석/조회 → 본인 목록·상세·근거·초안 확인 → 별도 공개/숨김 → 대표 없는 기본 링크 → 비로그인 열람.

서비스용 LLM 미선정은 제공자 종속 설계를 제한한다. 로그인·동의·권한·자산·링크·업무 상태·보호/복구의 요구사항 분석은 계속하며, 구현이나 외부 전송 허가로 확대하지 않는다. 투자수익·시장 효과·일정 달성·전체 품질을 검증했다고 주장하지 않는다. [Q, H]
