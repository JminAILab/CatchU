## 우선순위 방식과 해석

**MoSCoW의 이번 제공 범위 분류 + 위험/연결 의존 우선 순서**를 사용한다. 첫 MVP의 Must는 M01~M07이며 후행 구현이어도 선택 사항으로 낮추지 않는다. 대표는 이번 제공에는 Won't이나 확정 후속 개발 범위, 부가 기능은 Won't이며 채택 미정 후보, G는 10월 제외로 구분한다. 별도 Should/Could를 억지로 채워 필수 기능을 축소하지 않는다.

실제 공수·도달 사용자 수·가용량 근거가 없어 RICE/WSJF 숫자 점수나 완료일을 만들지 않는다. Must 항목의 총량이 가용량 안에 들어간다는 뜻도 아니다. 아래 순서의 P1/P2는 **연결 순서**, 범위 상태의 대체값이 아니며 Projects 필드를 자동 변경하지 않는다.

## 선후 관계·병행 가능한 준비

기능 가치 흐름: `IB01 → IB02 → IB03 → IB04 → IB05를 포함한 링크 조건 완비 → IB07 최종 검증`. IB06은 모든 구간의 조건이다. IB07 환경 요구·배포/복구 계획과 각 영역 계약 초안은 앞에서 준비할 수 있다. 이 맵은 정해진 AI-DLC 단계/승인을 생략하는 경로가 아니다.

- 지금 병행 가능한 입력: A/D 인증·선택/동의·진행/실패 상태, E/F 요청/결과·근거 범위, C 링크 조건·열람 계약, H 환경 요구, I 연결 쟁점/시험 목록. 각 담당은 연결 상대와 먼저 검토하고 기존 초안을 재사용한다.
- B 의존 차단점: D→B 이동 책임·E↔B 결과 영속화/식별·B↔C 공개 조회의 **최종 합의와 관련 구현 착수 전** B 담당/지원 확정. 전체 범위 정리·독립 계약 초안까지 차단하지 않는다.
- 팀원 1 대안 적용 시: F 최소 경로 → 최소 B → 연결 검증을 순차 계획하는 안으로 검토하고 H 실행/복구·I 재시험 시간을 별도 확보한다. 팀원 2의 E↔B 계약 검토, 팀원 3의 D/B/C 연결 검토는 본래 경계 작업이며 B 구현 지원은 별도 합의가 필요하다.
- 순서·지원·재시험 시간을 실제 가용량이 감당하지 못하면 지원/제공일 등을 재검토한다. 대표·부가 후보 후속화만으로 일정 여유가 확보됐다고 계산하지 않는다.

### 자료 사용에 따른 착수 제한 적용

| 구분 | IB02 및 관련 연결에 적용할 기준 |
|---|---|
| 과거 실험 자료·결과 사용 | 원문·발췌·응답·저장 결과·미확인 후보의 접근·복구·복사·전송·실행/시험 데이터 사용은 이번 수용으로 허용하지 않음. 삭제 의무 자료를 복구·새 사본 생성으로 우회하지 않으며 처리 증거를 재사용 허가로 바꾸지 않음 |
| 과거 자료 비의존 새 구현 | 승인 문서·비원문 결론·합성 자료 기반 새 코드·시험·모의 연결은 보조 7개 식별 미완료만으로 차단하지 않음. F의 새 처리·E–B 모의 연결도 자료 의존 여부로 판단. 담당자가 기존 설계/계약 검토에 입력·fixture 출처·의존 유무를 연결하고 후보 전수 무관함/삭제 증명을 요구하지 않음 |

동일한 식별 불확실성만으로 비의존 구현을 다시 보류하거나 같은 판단을 구현 직전에 반복하지 않는다. 자료 의존이 불명확한 부분만 보류하거나 합성/모의 경로로 분리하고 실제 관련 사본 잔존·과거 자료 의존·조건 위반이라는 새 사실이 생기면 해당 범위를 재검토한다. 실제 관련 사본 미처리에는 예외가 없으며 기존 기한과 별도 허용된 대상의 처리·부재·시각·방법 증거를 유지한다. 보조 7개는 관련성 미확인, 완료는 지정한 로컬 후보 3개 삭제 확인만이다. A 경로 부재의 삭제 경위나 일반 가능성 위치 전수 조사를 새 조건으로 추가하지 않는다. 추가 조사·열람·복구·삭제 없음.

상세 적용은 [Scope의 사본 현행 적용](scope-document.md)과 [Feasibility 제약 등록부](../feasibility/constraint-register.md)를 따른다. C03 담당자 경계 검토와 실제 이식 실행 담당 미배정은 유지하고, 서비스 모델 미선정·다른 착수 조건을 비의존 구분으로 해소하지 않는다. 새 기능·유닛·실행 허가·검증 예산을 만들지 않는다.

**첫 MVP 완료:** IB01~IB07의 실제 정상/거부/실패·권한·배포/영속/복구 증거와 각 영역 수정/재시험을 확인한다. 부분 성공·C01/C02 제한 성공·PR 머지·보드 상태로 전체 완료를 대신하지 않는다. 실제 시간·자료/결과/설정 버전·미검증 항목을 남기며 12월 NFR3 전체 품질 보장은 주장하지 않는다.

## Assumptions & Open Questions

- 모든 IB 항목의 개발 시간·순수 가용량·구체 지원/검토자·후속 개발일은 아직 확정하지 않았다. 기존 작업 시간/활동 비중 답변을 재사용하고 새 필수 시간표 제출을 요구하지 않는다.
- B는 팀원 4 일정/가용량 미확인·수행 불가 시 팀원 1 대안이라는 조건부 상태다. 팀원 2/3 지원은 세부/시간 미합의. 일정 위험을 숨기거나 자동 배정하지 않는다.
- 최소 근거 경로·수집 보안·최종 모델·NFR 상세와 OQ 해결은 후속 요구사항/설계·계약·구현·시험에서 수행한다. 신규 API/모델/인프라 실행은 이 백로그의 권한에 포함되지 않는다.
