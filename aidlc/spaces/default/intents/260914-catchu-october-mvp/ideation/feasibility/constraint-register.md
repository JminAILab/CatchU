**식별 불가가 계속될 때:** 이 범위가 공식 승인되면 동일한 식별 불확실성만으로 비의존 구현을 다시 보류하거나 같은 위험 판단을 구현 직전에 재질문하지 않는다. 입력 의존이 불명확하면 그 경로만 보류하거나 합성 입력·모의 연결로 분리한다. 이후 실제 관련 사본 잔존·과거 자료 사용 의존·조건 위반이라는 새 사실이 확인되면 영향받는 작업과 사본 처리 조건을 재검토한다. 이번 범위 구분은 구현 착수 자체의 승인이 아니며 C03·C04·C06·C07 및 다른 기존 설계/구현 전 조건·단계 승인도 유지한다. 서비스 모델 미선정을 해소하거나 생성 구현을 자동 착수하지 않는다.

**실제 관련 사본의 처리 의무·기한:** 실제 관련성이 확인된 실험 사본이 미처리라면 이번 예외 대상이 아니다. **2026-09-23 23:59 KST 또는 더 이른 Domain Design 승인/관련 구현 착수 전**의 기존 처리 조건을 유지한다. 별도 허용된 정확 대상의 처리와 경로 부재·처리 시각·방법의 증거가 필요하다. 보존 지시·확인 불가를 자동 기한 연장·포괄 면제로 사용하지 않는다. 보조 7개의 식별 불가만으로 실제 사본이라고 단정하지 않는다.
