## 고정 제약

- Next.js·NestJS·FastAPI / NCP / 수동 배포, 4인 팀, 10/1~2 발표와 추석 제외 조건을 유지한다. 월 서버·LLM/API 합산 약 160만 원은 계획 기준이지 예산 충족 증거나 자동 차단액이 아니다.
- 10월 실제 분석→근거·초안→별도 공개→링크 열람과 실패·중복·권한·내부 품질·운영·영속/복구 요구를 유지한다. 직접 문구 수정은 FR3.5에 따라 제공하지 않는다.
- 이력서 PDF는 12월. 기존 화면 담당 PR에서 병행하며 중복 작성하지 않는다.
- 전체 diff 복구를 필수화하지 않는다. 누락·잘림 탐지와 근거 범위 제한은 유지하며 수집 방식은 미채택이다.
- 추가 API 호출·모델 변경·인프라 생성은 별도 허용 없이 실행하지 않는다. 2~4시간 추정을 시간 배정으로 사용하지 않는다.
- 소유자 1인의 실험 동의를 공동 기여자 전원·서비스 전체 처리 동의로 확대하지 않는다. 삭제 약속을 후속 검토 때문에 연장하지 않는다.

## 자료 보관과 실행 제한의 이행

- 이번 실험 사본은 2026-09-16 13:45:40 KST에 삭제·부재 확인 완료. PoC 원본·기존 TheMe는 보존했다. 검토 후 7일 이내 및 관련 설계 승인/착수 전 삭제 조건을 충족했고 자동 보관 연장은 없다. 보존하는 것은 원문 없는 검증·비용·시간·설정·해시·삭제 기록이다.
- 기본 3회 + 인젝션 1회 + 보완 2회는 모두 사용했다. 새 재검증 제안은 호출 허용이 아니다. 삭제 자료를 복원하거나 새 원문을 전송할 때에는 새 입력·동의 범위·보관 기한·약관/가격·접근·호출 한도·추론 포함 비용 상한을 먼저 확인해야 한다.
- review-brief 설치 오류는 동일 2.8.1 원본 유지 보완과 13개 검사로 해소됐다. 이는 작성 전 확인 절차 복구이지 생성 품질 또는 feasibility 승인 증거가 아니다. 설치 변경은 별도 `5d5f627` 커밋으로 분리돼 있다.

## Assumptions & Open Questions

실제 담당이 없는 행을 ljm0850에게 전부 구현 배정하지 않는다. C04·C05·C07·C09·C11·C12는 책임 확정과 실행 증거가 남아 있다. C01의 2~4시간, 근거 처리 기준 1~2시간은 제한된 검토 추정이며 전체 제품 구현 견적이 아니다. 실제 시간 배정·최종 대안·세부 통제 수치는 후속 단계에서 결정한다. 실패 시 재검토 절차는 [평가서 일정 조건](feasibility-assessment.md)과 [RAID 로그](raid-log.md)에 연결한다.
