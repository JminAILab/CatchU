보조 7개 식별 미완료의 위험은 남긴다. 실제 관련 사본 잔존·과거 자료 의존·조건 위반이라는 **새 사실**이 생기면 그 영향 범위를 재검토하며, 자료 의존이 불명확한 경로만 보류하거나 합성/모의 경로로 분리한다. 기존 의무의 기한 초과는 지연 사실로 추적하고 자동 연장하지 않는다. 동일한 미확인 상태만으로 이미 수용한 비의존 구현 범위를 다시 판단하지 않는다. 서비스 모델 미선정과 다른 착수·외부 처리 조건은 별도로 유지한다.

A는 조회 시점의 지정 경로 부재로 남기고 삭제 경위·시각 규명을 새 조건으로 만들지 않는다. 일반 가능성 위치 전수 조사·공급자 물리적 삭제 증명을 추가하지 않는다. 기존 비원문 기록만 재사용했으며 추가 메타데이터 조회·원문 열람·복구·삭제·실험 호출은 없다.

## 재검토·인계 원칙

연결된 수용 기준 미달, 정해진 시점 초과, 핵심 후보 전부 보류, 안전 통제 실패 또는 실제 가용량 부족을 알게 되면 ljm0850가 #37 및 해당 작업에 근거·영향·선택 가능한 대응을 남긴다. 관련 착수·실자료 처리를 조건 미충족 상태로 진행하지 않고 즉시 실행 가능성과 일정을 다시 검토한다. 구체 설계·구현은 해당 후속 단계에서 담당을 정해 수행하며, 이 로그를 인프라 구축·서비스 코드 이식·추가 LLM 호출 지시로 사용하지 않는다.
