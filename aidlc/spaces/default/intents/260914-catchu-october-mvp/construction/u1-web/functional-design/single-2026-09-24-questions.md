### Q3. 내 자산 화면 구조는 무엇을 대체하며 어떻게 배치하는가?

[Answer]: U1 web `functional-spec.md`에 「내 자산 화면 구조」 절을 추가한다. 첫 문장은 다음과 같이 쓴다.

- 자료 탭은 Catch 탭 하나. 포트폴리오·자기소개서·이력서는 준비 중 탭으로 안내만 보인다.
- Catch 위쪽에 저장소 연결 관리 영역과 [연결 관리] 모달을 둔다. 미연동이면 프로필의 GitHub 연동으로 안내하고, 성공 뒤 Catch 탭의 연결 관리로 돌아온다. 모달 자동 열기는 담당 개발 이슈에서 정한다. 홈 CTA 목적지도 이 영역이다.
- 모달 위쪽은 분석 요청이 접수된 연결 저장소 목록이다. 상태 아이콘을 누르면 아코디언에서 상태를 확인한다. 성공·부분 실패는 저장소 Catch 보기, 실패는 재요청으로 연결한다. 아래쪽은 연결 가능한 저장소 선택·동의·요청이며 동의 내용을 버튼 앞에 보이고 버튼 하나로 동의와 요청을 한다.

- 재요청은 고지 요약과 [동의하고 다시 요청] 버튼 하나로 새 동의·새 요청을 만든다. 연결 해제는 제공하지 않는다.
