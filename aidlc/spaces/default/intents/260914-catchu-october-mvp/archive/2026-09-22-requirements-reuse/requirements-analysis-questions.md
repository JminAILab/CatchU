### 결정이 필요한 시점과 이전 기록의 관계

- **이번 Requirements Analysis:** 미선정, 용도 구분, 선정 기준·필요 증거·영향 경계를 기록한다. 과거 C06/D19의 “requirements-analysis OQ11 답변 시까지”에 대해 이번 사용자 답변은 미선정 유지와 기준 정리다. 기존 기록을 소급 변경하거나 C06을 충족으로 닫지 않는다. OQ11은 상태 확인 완료·최종 결정 미완료로 남긴다.
- **후속 설계/계약:** 제공자와 무관한 도메인·권한·상태·업무 결과 요구사항은 계속한다. 제공자별 입력 한도, 요청/응답 구조, 오류 코드, 처리 위치·보관 설정, 비용·지연·동시성에 의존하는 부분은 미결을 표시한다. 해당 제공자 종속 설계의 승인·계약 확정 전에 필요한 선택과 증거를 갖추는 것을 후속 결정 경계로 제안한다. 전체 설계 중단이나 현 단계의 제공자 고정은 요구하지 않는다.
- **기존 최종 안전 경계:** 늦어도 생성 구현·실사용자 자료의 외부 전송 전에는 서비스 제공자·모델·등급과 이용 조건을 확인한다. 조건 미충족이면 해당 작업은 진행하지 않는다. 추가 호출 금지는 별도의 명시적 허가 전까지 계속 유지한다.
- **다른 조건의 기한 보존:** C01/C02·PoC 수용·자료 삭제·안전 수집·환경/복구의 기존 담당·확인 기한은 모델 미선정을 이유로 연장하지 않는다. 특히 실험 사본 삭제 확인은 2026-09-23 23:59 KST 또는 domain-design 승인/관련 구현 착수 중 더 이른 경계를 유지하며 완료로 추정하지 않는다.
