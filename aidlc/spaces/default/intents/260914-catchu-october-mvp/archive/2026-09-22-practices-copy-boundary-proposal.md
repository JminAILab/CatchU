# Practices Discovery — 자료 사용 조건의 최소 반영 제안

이 문서는 독립 지원 검토용 제안이다. 공식 산출물·질문·상태·메모리를 수정한 기록이나 단계 승인 기록이 아니다. 기존 승인 인계의 적용 관계만 다루며 지원자의 기여·결론을 포함하지 않는다.

## 기존 보존 원칙

- Q1 공통 작업·검사·오류/로그 절차와 브랜치 변경안 보류, Q2 `Methodology: custom` 및 기존 `Ordering`, Q3 담당별 최소 연결 우선과 첫 결과의 별도 승인을 유지한다.
- 기존 다섯 관행 중 Way of Working·Walking Skeleton·Deployment는 재사용한다. Testing Posture와 Code Style에는 아래 적용 항목만 추가한다.
- 기존 Mandated 10개·Forbidden 8개 문구를 보존하고 최신 적용 관계를 설명하는 ALWAYS 한 항목만 추가한다. `project.md`의 기존 사본 삭제 의무를 직접 수정하지 않는다. 단계 승인 후 공식 `practices-promote`가 기존 규칙을 보존하며 추가 적용 문구를 반영하도록 한다.
- 기존 본문·출처·확인·승인·검토·회고는 보존한다. 과거 C03 경계 수용 대기 등 당시 표기는 날짜 있는 최신 적용으로 읽고 소급 수정하지 않는다.
- 기존 고정 HTTPS 근거 링크를 유지한다. 공식 승격되는 다섯 관행 절에 새 상대 링크를 넣지 않는다. 원본과 승격본에서 같은 근거를 가리키는지 검증한다.
- evidence에는 이번 최신 승인 적용·변경 영향·검증 범위만 날짜 있는 후속 절로 추가한다. timestamp는 최종 통합 시 실제 UTC 시각과 HEAD로 갱신하며 이전 값은 이력에 보존한다.
- C03 사용자 재사용/재설계 경계 수용은 완료이나 실제 담당자 검토는 미완료다. AI 관행 검토를 담당자의 수용으로 계산하지 않는다.
- 보조 7개 관련성 미확인과 실제 관련 사본 미처리를 구분한다. 추가 원문·사본 조회/열람/복구/삭제, 실험/API 호출, 구현·CI·배포·버전 변경은 하지 않는다.

## team-practices.md — Testing Posture 추가 2항

- 보조 7개는 실험 관련성 미확인으로 유지하며, 그 식별 미완료만 Domain Design 문서 승인 차단에서 제외한다. 완료 표기는 ‘지정한 로컬 후보 3개 삭제 확인’만 유지한다. 실제 관련 사본 미처리는 예외가 아니며 2026-09-23 23:59 KST 또는 더 이른 Domain Design 승인/관련 구현 착수 전 처리 의무·기한과 별도 허용된 대상의 처리·경로 부재·시각·방법 증거를 유지한다. 이를 전체 삭제 완료·관련 없음·포괄 면제나 재사용 허가로 해석하지 않는다. [H, U]
- C03 사용자 재사용/재설계 경계 수용은 완료다. F의 함수/소스·입력 의존, B/E의 등록·저장·전달, A/E/F의 요청·동의·귀속에 대한 담당자 검토 결과와 미결 담당·결정 시점은 Domain Design 승인 전에 연결한다. 실제 이식 실행 담당은 채택 코드 착수 전에 확정한다. 상세 API·시험 구현 전체를 지금 요구하거나 AI 문서 검증을 담당자 수용으로 계산하지 않는다. [H, U]

## team-practices.md — Code Style 추가 2항

기존 합성·비식별 자료 항목 다음에 추가한다. 기존 비식별 자료 우선 원칙을 과거 실험 자료의 비식별화·가공 허가로 해석하지 않는다.

- 자료 사용은 세 구분으로 적용한다. 과거 실험 원문·발췌·생성 응답·저장 결과의 접근·복구·복사·전송·실행/시험 자료 사용은 허용하지 않는다. 승인 문서·비원문 검토 결론·합성 자료 기반의 과거 자료 비의존 새 코드·시험·모의 연결은 보조 7개 식별 미완료만으로 차단하지 않는다. 새 실제 자료 수집·생성·외부 전송·실자료 시험은 기존 동의·모델·계약·안전성 및 별도 실행 허용 조건을 따른다. 이 구분은 구현 착수 승인이나 다른 조건의 면제가 아니다. [H, U]
- 담당자는 기존 설계/계약 검토에 입력·fixture 출처와 과거 자료 의존 유무를 연결한다. 같은 식별 불확실성만으로 비의존 구현을 다시 보류하거나 구현 직전에 같은 위험 판단을 반복하지 않는다. 의존이 불명확한 경로만 보류하거나 합성/모의 경로로 분리한다. 실제 관련 사본 잔존·과거 자료 의존·조건 위반이라는 새 사실이 확인되면 해당 범위만 재검토한다. 전수 부재/무관함 증명·일반 가능성 위치 조사·A 삭제 경위·공급자 물리 삭제 증명을 새 조건으로 추가하지 않는다. 추가 사본 접근은 허용되지 않았다. [H, U]

## discovered-rules.md — Mandated 추가 1항

- ALWAYS 이 intent의 기존 실험 사본 삭제 의무는 9/22 승인된 자료 사용 구분과 함께 적용한다. 실제 관련 사본 미처리의 의무·기한은 유지하고, 관련성 미확인 보조 7개의 식별 미완료만 Domain Design 문서 승인 차단에서 제외한다. 과거 자료 사용은 불허하며 과거 자료 비의존 새 코드·시험·모의 연결은 같은 식별 불확실성만으로 차단하지 않고, 새 실제 자료 처리는 기존 동의·모델·계약·안전성·별도 실행 조건을 따른다. 기존 담당 설계/계약 검토에 입력·fixture 출처와 과거 자료 의존 유무를 연결하고, 같은 불확실성으로 구현 직전 같은 판단을 반복하지 않으며 새 사실이 확인된 영향 범위만 재검토한다. 이를 삭제 완료·관련 없음·포괄 면제나 구현/외부 처리 허가로 사용하지 않는다.
