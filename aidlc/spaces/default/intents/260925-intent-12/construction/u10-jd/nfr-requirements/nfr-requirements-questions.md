# U10 비기능 요구사항 작성 전 확인

대상: u10-jd, 비기능 요구사항 단계. 기능 설계는 2026-11-02 사용자 승인을 받았고, R-01 수정·재검토와 승인 기록은 커밋 `47302098`에 보존했다. 이 문서는 비기능 산출물 생성 전 요약이며 단계 완료 승인이나 구현 승인이 아니다.

## 근거와 기존 결정

상류의 확정 답을 다시 묻지 않는다. 이번 단계는 아래 근거에서 U10에 적용되는 조건을 검증 가능한 요구사항으로 정리한다. 새로운 제품 정책·성능 수치·기술 선택을 요구하는 미결은 확인되지 않았다.

| 주제 | 이어받을 결정 | 직접 근거 |
|---|---|---|
| 권한과 격리 | JD·실행은 본인만 관리·조회한다. 요약 접수·재열람마다 유효 링크, 로그인 회원, 실행자와 발행본의 일치를 확인한다. 작성자도 받은 사람 링크 조건을 우회하지 않는다. | 기능 명세 §3·§4·§8, BR1.1·BR2.2·BR4.2, NFR1, C-10·C-11·C-12 |
| 입력·호출·규모 | 제목 200자·본문 20,000자, 요구사항 1~20줄·각 2,000자, 검색 최대 6개·조각 최대 1,000자, 목록 20개씩을 유지한다. 길이는 UTF-16이다. 요구사항별 순차 검색·생성 최대 1회이며, 정상 생성 입력 최대 8,000자는 공용 80,000자 안에 든다. 접수 전과 실제 생성 직전의 검사를 구분한다. | 기능 명세 §3~§6·§9, BR1.2·BR2.1·BR3.1·BR3.2, NFR4 |
| 처리 시한과 신뢰성 | 접수부터 큐 대기를 포함해 20분의 전체 시한을 둔다. 완료 시간 보장은 아니다. 실행 저장·횟수 차감을 한 트랜잭션으로 묶고 커밋 후 큐에 등록한다. 자동 재시도·중간 재개·실패 횟수 환급은 없다. 등록 실패·유실은 상태 조회 시 시한으로 실패를 확정한다. | 기능 명세 §4·§6·§7, BR2.3·BR2.4·BR4.1, C-02·C-03, NFR4 |

## 모호성·범위 점검

- 20분은 실행 종료를 판정하는 시한이며 응답 지연·처리 성능 보장이 아니다. 상류 NFR4가 추가 시간·가동률·복구 수치를 금지하므로 임의의 SLO·RTO·RPO·동시 사용자 목표를 만들지 않는다.
- R-01은 승인된 기능 설계에서 해소됐으며 이번 단계에서 개별 생성 시간 초과 코드를 다시 나누지 않는다.
- 기계적 인용 대조와 합성 시험은 실제 AI 근거 품질의 충족 증거가 아니다. NFR3 전체를 미적용으로 지우지 않고 JD 비교 기록과 질의응답 전용 평가를 구분해 추적한다.
- 외부 AI 서비스의 최신 약관 검증·실제 외부 호출·실제 사용자 자료 검사는 이번 문서 정리에 포함하지 않는다. 공용 제공자 선택과 조건 확인 책임을 U10의 검증 완료로 주장하지 않는다.
- 성능·보안·확장성·신뢰성·관측성·기술 결정 문서 6개와 추적표 1개를 작성한다. 상류 NFR1~NFR7을 빠짐없이 추적하고 상세 항목은 NFRx.y로 연결한다.
