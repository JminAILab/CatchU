# U2 공용 기반 — 신뢰성 요구사항

## Sources

작성일: 2026-10-27. 입력: [U2 기능 명세](../functional-design/functional-spec.md)(functional-spec)의 상태 전이·시나리오, [U2 업무 규칙](../functional-design/rules.md)(rules)의 BR1·BR3·BR5~BR7, [요구사항](../../../inception/requirements-analysis/requirements.md)(requirements)의 NFR5~NFR7과 FR6.8·FR14.10, [계약 요약](../../../inception/contract-design/contract-summary.md)(contract-summary)의 C-02·C-06과 「에러 대응 최소선」, [비기능 질문·답변](nfr-requirements-questions.md) Q2.

## 원칙

가동률·복구 시간 목표는 두지 않는다(NFR4). 신뢰성은 "실패를 숨기지 않고, 접수와 완료를 구분하며, 끝나지 않은 일은 시한으로 실패가 되고, 다시 시도는 사람이 한다"(에러 대응 최소선 1~4)로 정한다.

## 요구사항

| ID | 요구사항 | 확인 방법 | 근거 |
|---|---|---|---|
| NFR5.4 | 처리기는 결과를 쓰기 전에 부모 행(발행본·실행)을 확인하고, 없거나 FAILED이거나 시한이 지났으면 저장하지 않는다. 외래 키 위반은 다시 시도하지 않고 버린다 | 시나리오 S21 | BR5.7, FR14.10, AC14.1.6 |
| NFR5.5 | 탈퇴 2~4단계 중 실패하면 1단계(접근 차단)는 되돌리지 않고 500 `WITHDRAWAL_FAILED`로 끝난다. 회원은 다시 로그인해 탈퇴를 다시 요청할 수 있다. 2단계 삭제·재처리는 두지 않는다 | 시나리오 S25 | BR7.4, FR14.1 |
| NFR6.1 | 작업 등록 실패는 예외 없이 `ENQUEUE_FAILED`로 돌려주고, 상태는 시한이 지나 읽힐 때 FAILED가 된다. "대기"로 영원히 남지 않는다 | 시나리오 S19 | BR5.2·BR5.4·BR5.5, C-02 |
| NFR6.2 | 큐 작업은 시도 1회, 재시도·backoff 없음, 정체된 작업은 다시 처리하지 않는다(maxStalledCount 0). 끝나거나 실패한 작업은 2시간 남긴다. 각 Unit의 처리 시한이 2시간보다 길면 보관 시간을 그 이상으로 올린다 | 설정 확인, 시험 | BR5.2·BR5.6, Q2(비기능), FR6.8 |
| NFR6.3 | 처리기 예외는 삼키지 않고 kind·runKey·오류 종류를 로그로 남긴다 | 시험 | BR5.6, team.md Code Style |
| NFR6.4 | Claude 호출 실패는 `AiProviderError`로 호출 Unit에 올리고 게이트는 다시 부르지 않는다. 파일 저장소 오류는 `StorageUnavailable`로 올린다 | 시험 | U1 BR2.4, BR6.3, C-01·C-05 |
| NFR6.5 | 기능 사이 실패 시험은 보호 흐름 3개만 둔다. 동시 요청·재전송·늦은 결과의 기능별 세부 시험은 두지 않는다(단, 하루 횟수 원자성 S3과 늦은 결과 버림 S21은 U2 계약의 핵심이라 둔다) | 시험 목록 | NFR6, 에러 대응 최소선 6 |
| NFR7.1 | 한도 도달은 "오늘 한도에 도달했습니다"로, 동의 필요는 동의 창으로, 탈퇴 실패는 "탈퇴를 끝내지 못했습니다. 팀에 알려 주세요"로 구분해 안내한다 | 화면 확인 | BR1.4·BR2.2·BR7.4, NFR7 |
| NFR7.2 | 결과 항목은 근거 원문이 붙은 항목, 'AI 해석', 서버 안내(SERVER_NOTICE)를 구분할 수 있는 값으로 내보낸다. 화면 표시는 호출 Unit이 한다 | 시나리오 S16 | BR3.9·BR4.7, NFR7, FR6.5 |

## 겪을 수 있는 실패와 결과

| 실패 | 사용자에게 보이는 것 | 남는 상태 |
|---|---|---|
| Redis 끊김(등록) | 접수는 성공, 나중에 실패 | PENDING → 시한 뒤 FAILED |
| Claude 호출 실패 | 그 실행 실패 | 호출 Unit이 FAILED 기록 |
| DB 잠금 3초 초과 | 500 | 롤백 |
| 탈퇴 2~4단계 실패 | 탈퇴 실패 안내 | 접근 차단은 유지, 회원 행 남음 |
| 늦은 결과 | 없음 | 저장 거부, 버림 |
