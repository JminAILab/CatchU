### 유지할 검사 경계

- Must Have 50개, Should Have 16개, Could Have 2개이며 US·AC 식별자 중복은 없다. 비필수·후순위는 확인된 핵심 수준을 유지한다. 실제 구현·검사 통과를 뜻하지 않는다.
- 현재 자료의 숨김/철회와 이미 발행한 고정 공유본의 독립 조건을 US1.4·US2.2·US4.3·US5·US13에서 구분했다. 고정본에 원본 공개 상태를 다시 적용하면 안 된다는 반례가 있다.
- 같은 링크의 CatchU JD/AI 합산·연결 변경 초기화 금지와 회원 단위의 여러 도구 MCP 합산이 US6.4·US13.1에서 분리됐다. 외부 LLM 사용을 CatchU AI 호출로 합산하지 않는 기준도 유지됐다.
- 연락처 전달 당시 값, 상대 회원 한정, 역할/차단/운영 회복 후 재동의, 제안별 전체 중단은 US12.1·US12.2에서 검사 가능하다. 수락과 연락처 동의, 계정 차단과 일반 열람을 혼동하지 않는다.
- 제안 전달 중복 집계·기간 경계, 수락/철회 경합, 기업 종료 성공 후 탈퇴 실패, 알림 조회 실패와 분석 실패를 각각 다룬다.
- OQ1~15의 숫자·법적 적용·검증 계획·담당 확정은 현재 승인된 이연 조건이다. 이를 미응답 결함으로 삼거나 임의의 한도·응답 시간·새 품질 목표를 추가하지 않는다. `traceability.json`은 lead가 작성 중이므로 파일 부재를 결함으로 등록하지 않는다.
